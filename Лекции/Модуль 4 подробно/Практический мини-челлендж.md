### 🔹 Челлендж 1. FizzBuzz

📋 **Условие задачи:**

Вывести числа от 1 до 100, но:

- вместо чисел, кратных 3, вывести `Fizz`,
- вместо чисел, кратных 5 — `Buzz`,
- если число кратно и 3, и 5 — вывести `FizzBuzz`.

---

#### ✅ Вариант 1. Стандартный `if / else`

```php
for ($i = 1; $i <= 100; $i++) {
    if ($i % 3 === 0 && $i % 5 === 0) {
        echo "FizzBuzz\n";
    } elseif ($i % 3 === 0) {
        echo "Fizz\n";
    } elseif ($i % 5 === 0) {
        echo "Buzz\n";
    } else {
        echo $i . "\n";
    }
}
```

🔍 **Обсуждение:**

- Почему порядок проверок важен?  
    👉 Сначала проверяем `3 и 5`, чтобы не пропустить общие случаи.

- Можно ли заменить `elseif` на `if`?  
    👉 Да, но будет проверка всех условий, даже если одно уже выполнилось.


---

#### ✅ Вариант 2. Без `else`, с объединением строк

```php
for ($i = 1; $i <= 100; $i++) {
    $output = '';

    if ($i % 3 === 0) $output .= 'Fizz';
    if ($i % 5 === 0) $output .= 'Buzz';

    echo $output !== '' ? $output : $i;
    echo "\n";
}
```

💡 **Преимущество:** меньше вложенности, легче добавлять новые правила (например, для 7 → Bang).

---

#### ✅ Вариант 3. Тернарный оператор

```php
for ($i = 1; $i <= 100; $i++) {
    echo (($i % 3 === 0 ? 'Fizz' : '') .
          ($i % 5 === 0 ? 'Buzz' : '') ?: $i) . "\n";
}
```

⚠️ Требует пояснения: здесь `?: $i` используется как null-coalescing, если строка пустая — вывести число.

### 🔹 Челлендж 2. Факториал

📋 **Условие задачи:**

Найти факториал заданного числа `n`.  
Факториал — это произведение всех целых чисел от 1 до `n`.  
Например:  
`5! = 5 × 4 × 3 × 2 × 1 = 120`

---

#### ✅ Вариант 1. Через цикл

```php
function factorial($n) {
    $result = 1;
    for ($i = 2; $i <= $n; $i++) {
        $result *= $i;
    }
    return $result;
}

echo factorial(5); // 120
```

🧠 Пояснение:

- Начинаем с 1, чтобы `result *= $i` не умножал на 0.
- Цикл идёт с `2`, т.к. умножение на 1 не влияет.

---

#### ✅ Вариант 2. Рекурсия

```php
function factorial($n) {
    if ($n <= 1) return 1;
    return $n * factorial($n - 1);
}
```

⚠️ **Вопрос классу:**  
Что произойдёт при `factorial(0)`?  
👉 По определению, `0! = 1`.
