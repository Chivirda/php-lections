
## 🔄 **Блок 2. Циклы в PHP**

🕒 **Время: 0:20–0:35 (15 минут)**  
🎯 **Цель:** изучить все типы циклов в PHP, понять, где уместно применять каждый из них, и как использовать управляющие директивы `break`, `continue`, а также метки (labels) для выхода из вложенных циклов.

---

### 🔹 1. `while` — цикл с предусловием

**Синтаксис:**

```php
while (условие) {
    // тело цикла
}
```

**Пример:**

```php
$i = 0;
while ($i < 3) {
    echo $i . PHP_EOL;
    $i++;
}
```

🧠 **Когда использовать:** если заранее неизвестно, сколько раз повторится цикл — пока условие выполняется.

---

### 🔹 2. `do … while` — цикл с постусловием

**Синтаксис:**

```php
do {
    // тело цикла
} while (условие);
```

**Пример:**

```php
$i = 0;
do {
    echo $i . PHP_EOL;
    $i++;
} while ($i < 3);
```

📌 **Отличие от `while`:** тело цикла выполнится **хотя бы один раз**, даже если условие изначально ложно.

---

### 🔹 3. `for` — классический цикл со счётчиком

**Синтаксис:**

```php
for (инициализация; условие; обновление) {
    // тело цикла
}
```

**Пример:**

```php
for ($i = 0; $i < 5; $i++) {
    echo $i . PHP_EOL;
}
```

🧠 **Удобен**, когда точно известно количество итераций.

---

### 🔹 4. `foreach` — перебор элементов массива

**Синтаксис:**

```php
foreach ($array as $item) {
    // тело
}

foreach ($assoc as $key => $value) {
    // тело
}
```

**Пример:**

```php
$colors = ['red', 'green', 'blue'];
foreach ($colors as $color) {
    echo strtoupper($color) . PHP_EOL;
}
```

📌 Работает **только с массивами и объектами**, итерирует автоматически.

---

### 🔹 5. Директивы `break` и `continue`

#### `break` — прерывает текущий цикл:

```php
for ($i = 0; $i < 10; $i++) {
    if ($i === 3) break;
    echo $i . PHP_EOL;
}
// Выведет 0,1,2
```

#### `continue` — пропускает текущую итерацию:

```php
for ($i = 0; $i < 5; $i++) {
    if ($i % 2 === 0) continue;
    echo $i . PHP_EOL;
}
// Выведет 1,3
```

---

### 🔹 6. Метки (`labels`) и вложенные циклы

Иногда нужно выйти сразу из **нескольких вложенных циклов**.

**Пример:**

```php
outer:
for ($i = 0; $i < 3; $i++) {
    for ($j = 0; $j < 3; $j++) {
        if ($i === 1 && $j === 1) {
            break outer;
        }
        echo "$i-$j\n";
    }
}
```

📌 **Объяснение:** `break outer;` выходит не только из внутреннего `for`, но и из внешнего — до метки `outer`.

---

### ✅ Подведение итогов:

|Цикл|Где применяют|
|---|---|
|`while`|Пока выполняется условие|
|`do … while`|Нужно хотя бы одно выполнение|
|`for`|Нужен счётчик, фиксированное число итераций|
|`foreach`|Перебор массива/объекта|
|`break`|Прерывание цикла|
|`continue`|Пропуск текущей итерации|
|Метки|Выход из нескольких уровней|
