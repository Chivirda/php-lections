
## 🧩 **Блок 1. Условные конструкции в PHP**

🕒 **Время: 0:00–0:20 (20 минут)**  
🎯 **Цель:** научиться использовать разные виды условных операторов в PHP — `if/elseif/else`, тернарный оператор `?:`, null-объединение `??`, а также конструкцию `match` из PHP 8+.

---

### 🔹 1. `if / elseif / else` — базовая форма ветвления

**Синтаксис:**

```php
if (условие) {
    // код, если условие истинно
} elseif (другое_условие) {
    // код, если первое ложно, а это — истинно
} else {
    // код, если ничего не сработало
}
```

**Пример:**

```php
$temperature = 30;

if ($temperature > 35) {
    echo "Очень жарко!";
} elseif ($temperature > 20) {
    echo "Тепло";
} else {
    echo "Прохладно";
}
```

✅ **Комментарий:** Читаемая форма, позволяет создавать вложенные или каскадные проверки.

---

### 🔹 2. Тернарный оператор `?:` — компактная альтернатива `if`

**Форма:**

```php
условие ? значение_если_истинно : значение_если_ложно;
```

**Пример:**

```php
$is_admin = true;
echo $is_admin ? "Доступ разрешён" : "Доступ запрещён";
```

🧠 Используется часто для простых выражений, например, в HTML-выводе:

```php
<input type="checkbox" <?= $enabled ? 'checked' : '' ?>>
```

---

### 🔹 3. Null coalescing оператор `??` — проверка на null и undefined

**Форма:**

```php
$переменная ?? значение_по_умолчанию;
```

**Пример:**

```php
$username = $_GET['user'] ?? 'Гость';
echo "Привет, $username!";
```

📌 Работает как `isset($x) ? $x : значение`, но короче и безопаснее.

**Пример в массиве:**

```php
$data = ['name' => 'Anna'];
echo $data['email'] ?? 'Почта не указана';
```

---

### 🔹 4. `match` (с PHP 8.0) — альтернатива `switch`, но мощнее

**Синтаксис:**

```php
$result = match ($значение) {
    case1 => выражение1,
    case2 => выражение2,
    default => значение_по_умолчанию,
};
```

**Пример:**

```php
$code = 403;

$message = match ($code) {
    200 => 'OK',
    403 => 'Forbidden',
    404 => 'Not Found',
    default => 'Unknown error',
};

echo $message;
```

🔍 **Отличия от `switch`:**

- Не допускает «проваливания» (`fall-through`)
- Можно использовать выражения, возвращает значение
- Проверка **строгая** (`===`), а не `==`

### 💡 Практическое упражнение (обсуждение в классе, 2–3 минуты)

**Вопрос:**  
Что выведет следующий код?

```php
$value = null;
echo $value ?? 'по умолчанию';
```

✅ **Ожидаемый результат:** `по умолчанию`

### 📌 Итоги блока

|Конструкция|Использование|Особенности|
|---|---|---|
|`if / elseif / else`|Общие условия|Классика, удобна для ветвлений|
|`?:`|Простые условия|Компактная запись|
|`??`|Проверка переменной|Безопасная альтернатива `isset()`|
|`match`|Множественные значения|Строгая проверка, возвращает значение|
