
## 📦 **Блок 4. Массивы подробно в PHP**

🕒 **Время: 0:00–0:15 (15 минут)**  
🎯 **Цель:** научиться создавать массивы, использовать встроенные функции `array_*`, распаковывать массивы, изменять их с помощью `array_splice`, а также сортировать массивы с пользовательскими функциями (`usort`, `ksort`).

---

### 🔹 1. Создание массивов

#### **Простой индексированный массив:**

```php
$fruits = ['apple', 'banana', 'cherry'];
```

#### **Ассоциативный массив:**

```php
$user = [
    'name' => 'Anna',
    'age' => 25,
    'email' => 'anna@example.com'
];
```

#### **Многомерный массив:**

```php
$users = [
    ['name' => 'John', 'age' => 30],
    ['name' => 'Anna', 'age' => 25]
];
```

📌 **Особенности:**

- Ключи могут быть строками или числами.
- PHP автоматически нумерует, если ключи не указаны.

---

### 🔹 2. Полезные функции `array_*`

#### ✅ `array_map` — применяет функцию к каждому элементу:

```php
$squared = array_map(fn($x) => $x ** 2, [1, 2, 3]); // [1, 4, 9]
```

#### ✅ `array_filter` — отфильтровывает массив по условию:

```php
$even = array_filter([1, 2, 3, 4], fn($x) => $x % 2 === 0); // [2, 4]
```

#### ✅ `array_reduce` — сворачивает массив в одно значение:

```php
$sum = array_reduce([1, 2, 3], fn($carry, $x) => $carry + $x, 0); // 6
```

#### ✅ `array_keys`, `array_values`, `array_column`

```php
$keys = array_keys($user);       // ['name', 'age', 'email']
$values = array_values($user);   // ['Anna', 25, 'anna@example.com']
$names = array_column($users, 'name'); // ['John', 'Anna']
```

---

### 🔹 3. Распаковка массива (`...$array`) в аргументы функции

**Функция с тремя параметрами:**

```php
function greet($a, $b, $c) {
    echo "$a, $b, $c";
}

$args = ['Hello', 'world', '!'];
greet(...$args); // Hello, world, !
```

📌 Очень удобно, когда параметры динамически формируются из массива.

---

### 🔹 4. Модификация массива с `array_splice`

#### **Удаление и вставка элементов:**

```php
$colors = ['red', 'green', 'blue'];
array_splice($colors, 1, 1, ['yellow', 'orange']);
// ['red', 'yellow', 'orange', 'blue']
```

📌 **Сигнатура:**  
`array_splice(array &$input, int $offset, int $length = count($input), array $replacement = [])`

🧠 Часто используется в интерфейсах, например, при удалении и замене элементов в таблице/списке.

---

### 🔹 5. Сортировки массива

#### ✅ `usort` — сортировка с пользовательской функцией:

```php
$nums = [3, 1, 4, 2];
usort($nums, fn($a, $b) => $a <=> $b); // [1, 2, 3, 4]
```

#### ✅ `ksort` — сортировка по ключам:

```php
$assoc = ['b' => 2, 'a' => 1, 'c' => 3];
ksort($assoc); // ['a' => 1, 'b' => 2, 'c' => 3]
```

#### ✅ `uasort` — сортирует по значению, но сохраняет ключи:

```php
uasort($assoc, fn($a, $b) => $b <=> $a); // по убыванию, с ключами
```

### 🧪 Обсуждение / мини-упражнение (2–3 минуты)

> Как получить массив уникальных имён из массива пользователей?

```php
$names = array_unique(array_column($users, 'name'));
```

> Как отсортировать пользователей по возрасту?

```php
usort($users, fn($a, $b) => $a['age'] <=> $b['age']);
```
