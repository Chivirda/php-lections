
## 🛠️ **Блок 5. Функции в PHP**

🕒 **Время: 0:15–0:30 (15 минут)**  
🎯 **Цель:** понять, как определять функции, передавать аргументы по значению и по ссылке, использовать значения по умолчанию, переменное число аргументов, типизацию, а также как создавать анонимные и стрелочные функции.

---

### 🔹 1. Определение функции

**Синтаксис:**

```php
function имя_функции($аргументы) {
    // тело
    return $результат;
}
```

**Пример:**

```php
function greet($name) {
    return "Привет, $name!";
}

echo greet('Сергей');
```

---

### 🔹 2. Аргументы по значению и по ссылке

#### ✅ По значению (по умолчанию):

```php
function increment($num) {
    $num++;
    return $num;
}

$x = 5;
echo increment($x); // 6
echo $x;             // 5
```

#### ✅ По ссылке (используется `&`):

```php
function incrementRef(&$num) {
    $num++;
}

$x = 5;
incrementRef($x);
echo $x; // 6
```

📌 Передача по ссылке используется для изменения переменной в вызывающем коде. Часто применяется для изменения массивов, счётчиков, сбора результатов.

---

### 🔹 3. Значения по умолчанию

**Пример:**

```php
function greet($name = 'Гость') {
    echo "Привет, $name!";
}

greet();           // Привет, Гость!
greet('Мария');    // Привет, Мария!
```

📌 Значения по умолчанию всегда должны идти **в конце списка аргументов**.

---

### 🔹 4. Переменное количество аргументов (`...$items`)

**Синтаксис:**

```php
function sum(...$numbers) {
    return array_sum($numbers);
}

echo sum(1, 2, 3); // 6
```

🧠 Внутри функции `...$numbers` становится обычным массивом.

**Пример с передачей массива:**

```php
$data = [1, 2, 3];
echo sum(...$data); // тоже 6
```

---

### 🔹 5. Типы возвращаемых значений и типизация

**Объявление типов:**

```php
function square(int $x): int {
    return $x * $x;
}
```

📌 Можно указывать типы аргументов (`int`, `string`, `array`, `float`, `bool`) и возвращаемое значение (`: int`).

⚠️ С включённым `strict_types`, PHP будет строго проверять типы. Пример:

```php
declare(strict_types=1);
```

---

### 🔹 6. Анонимные функции (closures)

**Пример:**

```php
$log = function($msg) {
    echo "[log]: $msg\n";
};

$log('запуск скрипта');
```

📌 Полноценная функция, которую можно передавать как значение или вызывать через переменную.

**Пример передачи в `array_map`:**

```php
$squared = array_map(function($x) {
    return $x * $x;
}, [1, 2, 3]);
```

---

### 🔹 7. Стрелочные функции (PHP 7.4+)

**Синтаксис:**

```php
$double = fn($x) => $x * 2;
```

📌 Более краткий вариант, автоматически захватывает переменные из внешней области видимости.

**Пример:**

```php
$multiplier = 3;
$times = fn($x) => $x * $multiplier;

echo $times(4); // 12
```

---

### ✅ Сравнение: анонимная vs стрелочная

|Характеристика|Анонимная функция|Стрелочная функция|
|---|---|---|
|Синтаксис|`function(...) { ... }`|`fn(...) => ...`|
|Объём кода|Больше|Короткая запись|
|Захват переменных|Только через `use()`|Автоматически|
|Возвращаемое значение|`return` обязательный|Возвращает по умолчанию|

---

### 📌 Подведение итогов:

|Что изучили|Пример|
|---|---|
|Функции и `return`|`function hello() { return ... }`|
|Аргументы по значению/ссылке|`$x`, `&$x`|
|Значения по умолчанию|`function($x = 10)`|
|Переменное число аргументов|`...$args`|
|Типизация|`int`, `: array`, `strict_types`|
|Анонимные и стрелочные|`function`, `fn()`|
