
## ⏱️ 0:25–0:35 — **Date & Time API**

### 🎯 Цель блока:

Научиться работать с датой и временем в PHP: получать текущую дату, форматировать, производить арифметику (разница между датами), учитывать часовые пояса.

---

### 🧩 Зачем вообще API для даты?

- Время = не просто строка, а объект с кучей особенностей:
    - часовые пояса,
    - форматирование в разных странах,
    - переходы на летнее/зимнее время,
    - таймстемпы (числа),
    - разница между двумя моментами времени.

### 📅 Базовые классы

#### ✅ `DateTime` (мутабельный)

Можно менять после создания: `->modify()` изменяет сам объект.

#### ✅ `DateTimeImmutable` (рекомендуется)

**Неизменяемый** объект — любые изменения создают новый.

```php
$now = new DateTimeImmutable(); // текущая дата и время
```

📌 Почему `Immutable` — это хорошо:

- Поведение предсказуемо.
- Нет "неожайно перезаписанных" значений.

---

### 🕓 `date_default_timezone_set()`

По умолчанию PHP может работать в UTC.

Устанавливаем свой часовой пояс:

```php
date_default_timezone_set('Europe/Moscow');
```

🧠 Где взять список?  
[PHP Timezones](https://www.php.net/manual/en/timezones.php)

---

### 📐 Форматирование даты

Метод: `$date->format($pattern)`

Частые форматы:

|Буква|Описание|Пример|
|---|---|---|
|`Y`|Год (4 цифры)|`2025`|
|`m`|Месяц (2 цифры)|`05`|
|`d`|День|`09`|
|`H`|Часы (24ч)|`14`|
|`i`|Минуты|`30`|
|`s`|Секунды|`05`|

📌 Пример:

```php
$now = new DateTimeImmutable();
echo $now->format('Y-m-d H:i:s'); // 2025-05-09 14:30:05
```

---

### ⌛ Unix Timestamp

- Количество секунд с 1 января 1970 года (UTC).
- Используется для сравнения времени.

```php
$ts = $now->getTimestamp(); // int
```

🧠 Часто используется в API, БД, кэшах и т. п.

---

### 📊 Разница между датами

Используем метод `diff()`:

```php
$now = new DateTimeImmutable();
$newYear = new DateTimeImmutable('2026-01-01');
$diff = $now->diff($newYear);
```

`$diff` — объект `DateInterval`, в котором есть:

|Свойство|Описание|
|---|---|
|`days`|Кол-во дней|
|`y`|Лет|
|`m`|Месяцев|
|`d`|Дней (без учёта мес.)|

---

### 🧠 Интерактивная задача

#### **Вопрос студентам:**

> Сколько дней осталось до Нового года?

##### Решение:

```php
date_default_timezone_set('Europe/Moscow');
$now = new DateTimeImmutable();
$newYear = new DateTimeImmutable('2026-01-01');
$diff = $now->diff($newYear);
echo "До нового года: {$diff->days} дней";
```

---

### 🛠 Пример комплексный:

```php
date_default_timezone_set('Europe/Moscow');

$now = new DateTimeImmutable();
echo "Сегодня: " . $now->format('d.m.Y H:i') . PHP_EOL;

$birthday = new DateTimeImmutable('1991-04-25');
$age = $birthday->diff($now);

echo "Возраст: {$age->y} лет, {$age->m} месяцев, {$age->d} дней" . PHP_EOL;
```
