
## ⏱️ 0:00–0:10 — **Статика vs Динамика**

### 🎯 Цель блока:

Показать студентам, почему копировать HTML «вручную» — это плохая практика в реальных проектах, и как шаблонизация решает эти проблемы.

---

### 🧱 **Что такое статическая вёрстка?**

**Статическая страница** — это обычный `.html`-файл, содержащий полностью готовую разметку. Она:

- не меняется без ручного вмешательства;
- не зависит от данных на сервере;
- идеально подходит для простых сайтов-визиток или одностраничников.

**Пример:**

```html
<!-- about.html -->
<html>
  <head>
    <title>О нас</title>
  </head>
  <body>
    <header>
      <nav>
        <a href="/">Главная</a>
        <a href="/about.html">О нас</a>
      </nav>
    </header>
    <main>
      <h1>О компании</h1>
      <p>Наша история началась в 2005 году...</p>
    </main>
    <footer>
      <p>© 2025, Все права защищены</p>
    </footer>
  </body>
</html>
```

---

### ⚠️ **Проблемы статических HTML-файлов в больших проектах:**

Когда таких страниц — десятки или сотни:

1. **Дублирование кода:** 
    - Один и тот же `header`, `footer`, `sidebar` копируется в каждый файл.
    - Любое изменение приходится делать вручную в каждом месте.

2. **Ошибки при обновлении:** 
    - Например, забыли обновить номер телефона в одном из десятков файлов.

3. **Нет переиспользования:** 
    - Нельзя повторно использовать «блок» разметки.
    - Невозможно вынести повторяющиеся куски в модуль.


---

### 🧠 **Что такое динамический подход?**

Вместо копирования и вставки мы переходим к **шаблонизации** — автоматическому подключению нужных частей страницы.

#### 🔄 Переход:

`HTML → шаблоны → модули`

Мы **выносим** повторяющиеся части в отдельные PHP-файлы и **подключаем их** в нужных местах с помощью `include`/`require`.

---

### 🧩 Пример до и после:

#### ❌ Статический подход:

```html
<!-- contact.html -->
<html>
  <head>
    <title>Контакты</title>
  </head>
  <body>
    <header>
      <h1>Моя компания</h1>
    </header>
    <main>
      <h2>Контакты</h2>
      <p>Телефон: 8-800-123-45-67</p>
    </main>
    <footer>
      <p>© 2025</p>
    </footer>
  </body>
</html>
```

#### ✅ Динамический подход с PHP:

**header.php**

```php
<header>
  <h1>Моя компания</h1>
</header>
```

**footer.php**

```php
<footer>
  <p>© 2025</p>
</footer>
```

**contact.php**

```php
<html>
  <head>
    <title>Контакты</title>
  </head>
  <body>
    <?php include 'header.php'; ?>

    <main>
      <h2>Контакты</h2>
      <p>Телефон: 8-800-123-45-67</p>
    </main>

    <?php include 'footer.php'; ?>
  </body>
</html>
```

---

### 🧭 Зачем это нужно в жизни:

- 📦 Упрощает структуру проекта.
- ⚙️ Обновление одной части — сразу для всех страниц.
- 📈 Позволяет переходить к фреймворкам (Laravel, Symfony), где шаблонизация — ключевая часть архитектуры.

---

### ✅ Итог:

**Динамическая генерация HTML** через шаблоны — это:

- гибкость,
- масштабируемость,
- поддерживаемость кода.
