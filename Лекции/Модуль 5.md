
## 📚 **Модуль 5: Из вёрстки — в шаблоны. Работа с файлами и временем**

### ⏱️ 0:00–0:10 — **[Статика vs Динамика](./Модуль%205%20подробно/Статика%20vs%20Динамика.md)**

#### 🔑 Ключевые пункты:

- В небольших проектах можно просто дублировать HTML-файлы и править вручную.
- В больших проектах это ведёт к:
    - дублированию кода (одна и та же шапка в десятках файлов);
    - ошибкам при обновлении (забыли поменять в одном месте);
    - отсутствию повторного использования.

#### 🧠 Основная мысль:

**HTML → шаблоны → модули.**  
Мы хотим:

- вынести повторяющееся (header, footer, sidebar) в отдельные файлы;
- подключать их автоматически;
- управлять отображением данных на лету (например, из базы или по времени).

#### 🛠️ Пример:

```html
<!-- До: -->
<html>
  <head>
    <title>Мой сайт</title>
  </head>
  <body>
    <h1>Заголовок</h1>
    <p>Контент</p>
    <footer>© 2025</footer>
  </body>
</html>

<!-- После: -->
<?php include 'header.php'; ?>
<p>Контент</p>
<?php include 'footer.php'; ?>
```

### ⏱️ 0:10–0:25 — **[Подключение файлов в PHP](./Модуль%205%20подробно/Подключение%20файлов%20в%20PHP.md): `include`, `require`, `_once`** 

#### 🔑 Ключевые различия:

|Функция|Ошибка при отсутствии файла|Повторное подключение|
|---|---|---|
|`include`|_Warning_, продолжит выполнение|Подключает каждый раз|
|`require`|_Fatal error_, скрипт остановится|Подключает каждый раз|
|`include_once`|_Warning_, но подключает только один раз||
|`require_once`|_Fatal_, но подключает только один раз||

#### 📌 Пути подключения:

- Относительные: `include 'parts/header.php';`
- Абсолютные: `include __DIR__ . '/parts/header.php';`

Почему лучше `__DIR__`?

- Устраняет ошибки при запуске из разных директорий (`cli`, `web`, `cron`).

### ⏱️ 0:25–0:35 — **[Date & Time API в PHP](./Модуль%205%20подробно/Date%20&%20Time%20API%20в%20PHP.md)**

#### 🔑 Современный подход:

- `DateTimeImmutable` — безопасен, не изменяет оригинальный объект.
- `date_default_timezone_set('Europe/Moscow')` — установка часового пояса.
- Форматирование:

```php
$now = new DateTimeImmutable();
echo $now->format('Y-m-d H:i:s');
```

#### ⏳ Разница с Unix Timestamp:

```php
$now = new DateTimeImmutable();
echo $now->getTimestamp(); // секунды с 1970 года
```

#### 🧩 Задача:

**Сколько дней до Нового года?**

```php
$now = new DateTimeImmutable();
$newYear = new DateTimeImmutable('2026-01-01');
$interval = $now->diff($newYear);
echo $interval->days;
```

### ⏱️ 0:35–0:45 — **[Лучшие практики](./Модуль%205%20подробно/Лучшие%20практики.md)**

#### 📌 1. **Front-controller (index.php)**

- Вход в приложение только через `index.php`.
- Внутри подключаем всё: роуты, конфиги, шаблоны.

#### Пример:

```php
<?php
require_once __DIR__ . '/config/config.php';
require_once __DIR__ . '/routes/web.php';
```

#### 📌 2. **Конфиги**

- Разбиваем на файлы в `config/`: `db.php`, `app.php`, `mail.php` и т.д.
- Загружаем через `require` или функцию:

```php
function config($name) {
    return require __DIR__ . "/config/{$name}.php";
}
```
