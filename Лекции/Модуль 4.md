### 🔹 1-й академический час (45 мин)

---

#### ⏱ 0:00–0:20 — **[Условные конструкции](./Модуль%204%20подробно/Условные%20конструкции.md)**

**1. if / elseif / else**

```php
$score = 85;

if ($score >= 90) {
    echo "Отлично";
} elseif ($score >= 75) {
    echo "Хорошо";
} else {
    echo "Попробуй ещё раз";
}
```

**2. Тернарный оператор `?:`**

```php
$age = 18;
echo ($age >= 18) ? "Совершеннолетний" : "Несовершеннолетний";
```

**3. Null-coalescing оператор `??`**

```php
$username = $_GET['user'] ?? 'Гость';
echo "Привет, $username!";
```

**4. `match` (с PHP 8)**

```php
$status = 404;

echo match ($status) {
    200 => 'OK',
    404 => 'Not Found',
    500 => 'Server Error',
    default => 'Unknown',
};
```

🧠 **Обсуждение:** преимущества `match` перед `switch`, отсутствие «проваливания» между кейсами, обязательность совпадения.

---

#### ⏱ 0:20–0:35 — **[Циклы](./Модуль%204%20подробно/Циклы.md)**

**1. while / do … while**

```php
$count = 0;
while ($count < 5) {
    echo $count++;
}
```

```php
$count = 0;
do {
    echo $count++;
} while ($count < 5);
```

**2. for / foreach**

```php
for ($i = 0; $i < 5; $i++) {
    echo $i;
}
```

```php
$items = ['a', 'b', 'c'];
foreach ($items as $item) {
    echo $item;
}
```

**3. break, continue**

```php
for ($i = 0; $i < 10; $i++) {
    if ($i === 5) break;
    if ($i % 2 === 0) continue;
    echo $i;
}
```

**4. Метки для вложенных циклов**

```php
outer:
for ($i = 0; $i < 3; $i++) {
    for ($j = 0; $j < 3; $j++) {
        if ($i === 1 && $j === 1) {
            break outer;
        }
        echo "$i-$j\n";
    }
}
```

---

#### ⏱ 0:35–0:45 — **[Практический мини-челлендж](./Модуль%204%20подробно/Практический%20мини-челлендж.md)**

📌 **FizzBuzz**

```php
for ($i = 1; $i <= 100; $i++) {
    echo ($i % 3 === 0 ? 'Fizz' : '') .
         ($i % 5 === 0 ? 'Buzz' : '') ?: $i;
    echo "\n";
}
```

📌 **Факториал (через цикл)**

```php
function factorial($n) {
    $result = 1;
    for ($i = 2; $i <= $n; $i++) {
        $result *= $i;
    }
    return $result;
}
```

📌 **Обсуждение вариантов:** рекурсивное vs итеративное решение, пограничные случаи, валидация.

#### ⏱ 0:00–0:15 — **[Массивы подробно](./Модуль%204%20подробно/Массивы%20подробно.md)**

**1. Создание массивов**

```php
$nums = [1, 2, 3];
```

**2. Функции `array_*`:**

- `array_merge`, `array_diff`, `array_filter`, `array_map`, `array_reduce`, `array_keys`, `array_values`, `array_column`
    

```php
$result = array_map(fn($x) => $x * 2, [1, 2, 3]); // [2, 4, 6]
```

**3. Распаковка `...$arr`**

```php
function sum($a, $b, $c) {
    return $a + $b + $c;
}
$args = [1, 2, 3];
echo sum(...$args);
```

**4. `array_splice`**

```php
$input = [1, 2, 3, 4];
array_splice($input, 1, 2, ['a', 'b']); // [1, 'a', 'b', 4]
```

**5. Сортировки**

```php
usort($arr, fn($a, $b) => $a <=> $b);
ksort($assocArr);
```

#### ⏱ 0:30–0:40 — **Практика: функция flatten**

🧑‍💻 Live-coding:

```php
declare(strict_types=1);

function flatten(array $input): array {
    $result = [];

    array_walk_recursive($input, function ($item) use (&$result) {
        $result[] = $item;
    });

    return $result;
}

print_r(flatten([1, [2, [3, 4]], 5]));
```

**Обсуждение:** почему используется `array_walk_recursive`, альтернатива — рекурсия вручную.
