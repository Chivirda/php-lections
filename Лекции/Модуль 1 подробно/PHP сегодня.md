
## 🔧 Актуальная версия — **PHP 8.3**

### Что нового в 8.3 (по состоянию на 2024–2025):

- **Typed class constants** — можно указывать типы для `const` в классах.
- **Dynamic class constant fetch** — доступ к `ClassName::{$const}`.
- **json_validate()** — удобная проверка JSON без декодирования.
- **Readonly improvements** — улучшенная работа с `readonly` свойствами.

> 📌 Суть: развитие идёт в сторону строгости и безопасности, но при этом язык сохраняет простоту.

## 🚀 JIT-компиляция и OPcache

### Что это такое:

- **OPcache** — кэширует скомпилированный байткод PHP, ускоряет повторный запуск.
- **JIT (Just-In-Time Compilation)** — с PHP 8.0: позволяет часть PHP-кода компилировать в машинный код на лету.

### Польза:

- **Быстрее** работает числовая математика, рекурсивные функции, генераторы.
- **Реальный выигрыш** — в проектах с тяжёлой логикой или при высоких нагрузках.

> 💬 Миф: «PHP медленный» — с OPcache и JIT это уже **давно не так**.

## 📦 Composer — ядро современной экосистемы

### Что такое Composer:

- Менеджер зависимостей (аналог pip, npm).
- Работает с `composer.json`, позволяет подключать библиотеки, автозагрузку, обновления.

### Примеры:

```bash
composer require guzzlehttp/guzzle
composer install
```

### Зачем он нужен:

- Упрощает работу с фреймворками: Laravel, Symfony.
- Централизованное хранилище — [Packagist.org](https://packagist.org/).

## 🌐 Доля PHP на рынке

- По данным [W3Techs](https://w3techs.com/), **PHP используется на ≈75% всех сайтов**, где известен серверный язык.
- WordPress — топовая CMS в мире (на PHP), управляет **более 40% всех сайтов**.
- Тысячам бизнесов не нужен модный стек — им нужен надёжный, дешёвый и масштабируемый PHP.

📊 _Примеры графиков, которые можно показать:_

- Доля языков на сервере (PHP vs Node.js vs Python).
- Популярность CMS по языкам.
- История версий PHP.
