
## 🔹 Простота деплоя

**Что это значит:**

- PHP — это **интерпретируемый язык**, который **работает сразу**, без компиляции.
- **Многие хостинги** (особенно shared-hosting, т.е. дешёвые виртуальные хостинги) **уже имеют поддержку PHP** по умолчанию.
- Чтобы задеплоить сайт на PHP, достаточно:
    1. Закинуть `.php` файлы на сервер (через FTP, SFTP, панель управления).
    2. Убедиться, что сервер поддерживает Apache или Nginx с PHP.
    3. Готово — сайт работает.

**Пример:**

```php
<?php echo "Привет, мир!"; ?>
```

Этот файл можно просто скопировать на сервер, и он будет работать.

🔧 _На других языках (например, Java, Node.js) нужно отдельно поднимать окружение, управлять зависимостями, запускать процессы._

## 🚀 Быстрый старт

**Что даёт:**

- Можно **запустить полноценный сайт за вечер**, даже без фреймворка.
- Не нужно ручной сборки, конфигураций, веб-серверов — всё уже готово.
- Большое количество бесплатных CMS и шаблонов на PHP позволяет быстро сделать блог, магазин или корпоративный сайт.

**Для студентов и новичков:**

- Это **порог входа, близкий к нулю**.
- Можно экспериментировать без сложной установки инструментов.

🧩 **PHP отлично подходит для обучения** веб-разработке и быстрых MVP (минимально жизнеспособных продуктов).

## 🏗️ Разнообразие фреймворков

**Самые популярные:**

- **Laravel** — самый популярный и «современный» PHP-фреймворк. Используется и в малом бизнесе, и в стартапах.
- **Symfony** — мощный, модульный фреймворк, часто используется в крупных корпоративных проектах.
- **Yii** — быстрый фреймворк с минимализмом и удобством, популярен в СНГ.
- **Slim / Lumen** — микрофреймворки для создания REST API.

**Что это даёт:**

- Каждый проект может выбрать фреймворк по уровню сложности.
- Есть поддержка MVC-архитектуры, ORM (Eloquent, Doctrine), шаблонизаторов (Blade, Twig), миграций, CLI-инструментов.

**Пример: Laravel**

```php
Route::get('/hello', function () {
    return 'Привет, Laravel!';
});
```

📦 Благодаря **Composer** и Packagist легко подключать любые библиотеки.
