
### ⏰ **0:00–0:12** — **[Иерархия Throwable](./Модуль%209%20подробно/Иерархия%20Throwable.md)**

#### 📌 Содержание:

- В PHP всё, что можно поймать через `catch`, наследуется от интерфейса `\Throwable`. 
- Есть два основных подкласса:  
    - `\Exception` — для обычных ошибок на уровне бизнес-логики;  
    - `\Error` — для фатальных ошибок, типа `TypeError`, `ParseError`.  
- Кастомные исключения позволяют выделять собственные типы ошибок.  

#### 🧑‍💻 Live-код:

```php
class ValidationException extends \Exception {}

try {
    throw new ValidationException("Некорректный email");
} catch (ValidationException $e) {
    echo "Ошибка валидации: " . $e->getMessage();
}
```

### ⏰ **0:12–0:22** — **[Перехват исключений](./Модуль%209%20подробно/Перехват%20исключений.md) try / catch / finally**

#### 📌 Содержание:

- Обработка исключений через `try / catch`.  
- Несколько `catch` для разных типов ошибок.  
- Блок `finally` выполняется всегда — даже при `return` или `throw`.  
- Использование `??` (null coalescing) — альтернатива для значений по умолчанию, вместо выброса исключений.  
- Re-throw: повторное возбуждение исключения после логирования.  

#### 🧑‍💻 Live-код:

```php
function divide($a, $b) {
    if ($b === 0) {
        throw new \DivisionByZeroError("На ноль делить нельзя");
    }
    return $a / $b;
}

try {
    echo divide(10, 0);
} catch (\DivisionByZeroError $e) {
    echo "Ошибка: " . $e->getMessage();
} finally {
    echo "\nЗавершение блока";
}
```

### ⏰ **0:22–0:32** — **[Строгая типизация](./Модуль%209%20подробно/Строгая%20типизация.md)**

#### 📌 Содержание:

- `declare(strict_types=1);` в начале файла включает строгую типизацию.  
- `typed-properties` (PHP 7.4+) — свойства с типами.  
- `union types` (`int|float`) — один из нескольких типов.  
- `intersection types` (PHP 8.1+) — **все указанные интерфейсы должны быть реализованы**.  
- `readonly` свойства (PHP 8.1) — можно задать только один раз (в `__construct`).  
- `enum` (PHP 8.1+) — ограниченные значения, альтернатива константам.  

#### 🧑‍💻 Live-код:

```php
declare(strict_types=1);

function sum(int|float $a, int|float $b): float {
    return $a + $b;
}

echo sum(2, 3.5); // 5.5

enum Status {
    case Draft;
    case Published;
}

class Article {
    public readonly Status $status;
    
    public function __construct(Status $status) {
        $this->status = $status;
    }
}
```

### ⏰ **0:32–0:42** — **[Генераторы и `yield`](./Модуль%209%20подробно/Генераторы%20и%20`yield`.md)**

#### 📌 Содержание:

- Генераторы (`yield`) создают **ленивые итераторы**, экономят память.  
- `yield` возвращает значение без завершения функции.  
- `yield from` — делегирует генерацию другому генератору.  
- Применимо для работы с большими массивами, файлами, API.  

#### 🧑‍💻 Live-код:

```php
function fibonacci($n): iterable {
    $a = 0; $b = 1;
    for ($i = 0; $i < $n; $i++) {
        yield $a;
        [$a, $b] = [$b, $a + $b];
    }
}

foreach (fibonacci(10) as $num) {
    echo "$num ";
}
```
