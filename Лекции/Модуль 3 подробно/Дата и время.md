
## 🕒 **Тема:** Работа с датой и временем в PHP

> **Цель:** Научиться создавать и изменять объекты даты и времени, понимать разницу между `DateTime` и `DateTimeImmutable`, правильно устанавливать часовой пояс и форматировать вывод.

---

### 📦 1. Класс `DateTime`

#### ✅ Создание объекта:

```php
$now = new DateTime();
```

- По умолчанию берёт **текущую дату и время**, а также системный часовой пояс.
- Поддерживает парсинг строки:

```php
$date = new DateTime('2025-12-31 23:59');
```

#### ⚙ Методы изменения:

```php
$now->modify('+1 day'); // изменит сам объект
$now->setTime(12, 0);
```

> 🧨 `DateTime` изменяет объект **внутри себя**.

---

### 🧊 2. `DateTimeImmutable`

#### Отличие:

`DateTimeImmutable` не меняет текущий объект — возвращает **новый**.

```php
$now = new DateTimeImmutable();
$tomorrow = $now->modify('+1 day');

echo $now->format('Y-m-d');     // сегодня
echo $tomorrow->format('Y-m-d'); // завтра
```

✅ Рекомендуется использовать в большинстве случаев, особенно в больших проектах или при написании API/сервисов.

---

### 🌐 3. Часовые пояса

#### Почему важно:

По умолчанию PHP может использовать системный часовой пояс, что вызывает **разные результаты на проде и локалке**.

#### Установка:

```php
date_default_timezone_set('Europe/Moscow');
```

- Можно задать в `php.ini` (рекомендуется):

```
date.timezone = "Europe/Moscow"
```


#### Получение текущего пояса:

```php
echo date_default_timezone_get();
```

---

### 🧮 4. Форматирование даты и времени

#### Метод `format()`:

```php
echo $now->format('Y-m-d H:i:s'); // 2025-05-05 12:30:00
```

- Частые форматы:
    - `Y-m-d` — дата
    - `H:i:s` — время
    - `d.m.Y` — русский стиль
    - `c` — ISO 8601 (альтернатива `DateTime::ATOM`)
    - `r` — формат RFC 2822

#### Пример:

```php
echo $now->format(DateTime::ATOM);
// 2025-05-05T14:25:00+03:00
```

---

### 🧪 Пример использования в проекте

```php
$date = new DateTimeImmutable('2025-01-01 00:00:00');
$end = $date->modify('+1 month');

echo "Акция действует до " . $end->format('d.m.Y');
```

---

### 🧠 Практика

> ✏️ **Упражнение:** создайте объект `DateTimeImmutable` с текущим временем. Затем:

1. Увеличьте дату на 7 дней.
2. Установите время на 18:00.
3. Выведите результат в формате `d.m.Y H:i`.

Пример решения:

```php
$d = new DateTimeImmutable();
$d = $d->modify('+7 days')->setTime(18, 0);

echo $d->format('d.m.Y H:i');
```

---

### 📌 Сравнение классов

|Особенность|`DateTime`|`DateTimeImmutable`|
|---|---|---|
|Изменяет себя|✅ Да|❌ Нет|
|Возвращает копию|❌ Нет|✅ Да|
|Безопасен в многопоточности/тестах|⚠ Не всегда|✅ Да|
|Поддержка методов|✅ Одинаково||

---

### 🛠 Подсказки и Best Practices

- Всегда **явно задавайте часовой пояс** — не надейтесь на дефолт.
- Используйте `DateTimeImmutable` — безопаснее и предсказуемее.
- Формат ISO-8601 (`DateTime::ATOM`) — лучший выбор для API и JSON.
- Для простых задач можно использовать `date()` + `strtotime()`, но это процедурный стиль и хуже читаем.

---

### 📚 Итоги

- В PHP нет встроенного примитивного типа даты: всегда используем объекты.
- Выбор между изменяемыми (`DateTime`) и неизменяемыми (`DateTimeImmutable`) влияет на архитектуру и ошибки.
- Знание часовых поясов и стандартных форматов критично для API.
