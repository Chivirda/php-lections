
## 🔖 **Тема:** Константы и перечисления (Enums) в PHP

> **Цель:** Научиться использовать константы и перечисления для создания безопасных, читаемых и расширяемых программных конструкций.

---

### 🔹 1. Константы (`const` и `define()`)

#### ✅ Что такое константа?

- Это **именованное значение**, которое нельзя изменить после определения.
- Используются для **настроек, флагов, ролей, статусов** и т.д.

---

### 📌 `const` — предпочтительный способ

```php
const MAX_USERS = 100;
```

- Работает в **глобальной области** или внутри классов.
- Статически определена на этапе компиляции.
- Не может использоваться вне функций, т.е. нельзя задать внутри `if`.

#### Пример:

```php
class Config {
  const APP_NAME = 'MyApp';
}
echo Config::APP_NAME;
```

---

### 📌 `define()` — старый, но гибкий способ

```php
define('API_KEY', 'abc123');
```

- Работает **везде**, можно вызывать динамически.
- Позволяет определять константы во время выполнения.
- Не поддерживается внутри классов.

> ❗Используйте `define()` только если `const` недоступен по каким-то причинам.

---

### 🧠 Когда что использовать?

|`const`|`define()`|
|---|---|
|Современный PHP|Подходит для старых версий|
|Только compile-time|Можно динамически|
|В классах|Только глобально|

### 🌀 2. Перечисления (enum) — PHP 8.1+

> **Enum (перечисление)** — специальный тип, ограниченный **заданным набором значений**.

#### 📦 Простое перечисление:

```php
enum Status {
  case Pending;
  case Approved;
  case Rejected;
}
```

- Используется как тип: `Status $status`
- Гарантирует, что значение может быть **только одно из перечисленных**

#### Использование:

```php
function setStatus(Status $status) {
  echo "Установлен статус: $status->name";
}

setStatus(Status::Approved);
```

---

### 🔢 Скалярные enum’ы (с привязкой к значению):

```php
enum Role: string {
  case Admin = 'admin';
  case User = 'user';
}
```

- Поддерживает привязку к `string` или `int`
- Имеет свойства:
    - `$role->value` → `'admin'`
    - `$role->name` → `'Admin'`

#### Пример:

```php
echo Role::Admin->value; // admin
```

---

### 💡 Зачем использовать enum?

- Безопасно: нельзя передать невалидное значение
- Автодополнение в IDE
- Упрощает миграцию к типизированному коду

---

### 🧠 Интерактив: Мини-квиз

> 🔍 **Вопрос:** Как лучше всего задать перечисление статусов заказа?

**Варианты:**

1. `const STATUS_PENDING = 1;`
2. `define('STATUS_PENDING', 1);`
3. `enum OrderStatus { case Pending; case Shipped; case Delivered; }`

✅ **Правильный ответ:** **3** — если вы используете PHP 8.1+, enum безопаснее, гибче и расширяемее.

**Обсуждение с аудиторией:**
- Чем плох подход с `const`? → Возможность дублирования, отсутствие группировки
- Какие плюсы у enum? → Типобезопасность, автодополнение, строгий контроль допустимых значений

### 🧪 Практика

> ✏️ Задание: создайте enum `UserType` с вариантами `Admin`, `Manager`, `Customer`, и напишите функцию, которая принимает `UserType` и возвращает строку приветствия.

**Пример:**

```php
enum UserType {
  case Admin;
  case Manager;
  case Customer;
}

function greet(UserType $type): string {
  return match($type) {
    UserType::Admin => 'Здравствуйте, администратор!',
    UserType::Manager => 'Добро пожаловать, менеджер!',
    UserType::Customer => 'Приветствуем, клиент!',
  };
}
```

### 🧾 Итоги

|Что|Когда использовать|
|---|---|
|`const`|Константы внутри классов|
|`define()`|Константы вне классов в старом коде|
|`enum`|Современный способ описания ограниченных наборов значений (PHP 8.1+)|
