
## 🕒 0:15–0:25 — **Операторы в PHP**

Операторы — это символы или конструкции, с помощью которых выполняются операции над значениями. В PHP они делятся на несколько групп:

---

### 🔹 1. **Арифметические операторы**

Применимы к числам (`int`, `float`):

|Оператор|Назначение|Пример|Результат|
|---|---|---|---|
|`+`|Сложение|`3 + 2`|`5`|
|`-`|Вычитание|`5 - 7`|`-2`|
|`*`|Умножение|`3 * 4`|`12`|
|`/`|Деление|`10 / 4`|`2.5`|
|`%`|Остаток от деления|`10 % 3`|`1`|
|`**`|Возведение в степень|`2 ** 3`|`8`|

**Примеры:**

```php
echo 7 % 3;      // 1
echo 2 ** 4;     // 16
```

---

### 🔹 2. **Строковый оператор**

PHP использует **только один оператор** для работы со строками:

|Оператор|Назначение|Пример|Результат|
|---|---|---|---|
|`.`|Конкатенация строк|`"Hello" . " World"`|`"Hello World"`|

**Пример:**

```php
$name = "Alice";
echo "Hello, " . $name; // Hello, Alice
```

---

### 🔹 3. **Логические операторы**

Работают с булевыми значениями (`true`, `false`).

|Оператор|Назначение|Приоритет|Пример|Результат|
|---|---|---|---|---|
|`&&`|И (и лев., и прав. true)|высокий|`true && false`|`false`|
|`||`|ИЛИ (хотя бы одно true)|высокий|
|`!`|НЕ (инверсия)|высокий|`!true`|`false`|
|`and`|И|низкий|`true and false`|`false`|
|`or`|ИЛИ|низкий|`true or false`|`true`|

**ВАЖНО:** `and` и `or` имеют **низкий приоритет** и часто используются для управления потоком:

```php
$loggedIn = false;
$user = $loggedIn and getUser(); // getUser() не выполнится
```

---

### 🔹 4. **Побитовые операторы**

Применимы к целым числам (`int`). Работают на уровне битов.

| Оператор | Назначение                | Пример    | Результат |
| -------- | ------------------------- | --------- | --------- |
| `&`      | Побитовое И               | `6 & 3`   | `2`       |
| `\|`     | `\|`                      | `6 \| 3`  | `7`       |
| `^`      | Побитовое исключающее ИЛИ | `6 ^ 3`   | `5`       |
| `~`      | Побитовая инверсия        | `~6`      | `-7`      |
| `<<`     | Сдвиг влево               | `3 << 2`  | `12`      |
| `>>`     | Сдвиг вправо              | `12 >> 2` | `3`       |

**Пример:**

```php
echo 6 & 3; // 2, потому что 110 & 011 = 010
```

---

### 🔹 5. **Операторы сравнения**

Сравнивают два значения и возвращают `true` или `false`.

| Оператор             | Назначение                          | Пример      | Результат |
| -------------------- | ----------------------------------- | ----------- | --------- |
| `==`                 | Равно (с приведением типов)         | `"5" == 5`  | `true`    |
| `===`                | Строго равно (без приведения типов) | `"5" === 5` | `false`   |
| `!=`                 | Не равно                            | `5 != 6`    | `true`    |
| `!==`                | Строго не равно                     | `"5" !== 5` | `true`    |
| `<`, `>`, `<=`, `>=` | Обычные числовые сравнения          | `2 < 5`     | `true`    |
| `<=>`                | Spaceship (сортировка: -1, 0, 1)    | `3 <=> 2`   | `1`       |

---

### 💡 **Интерактив — Демонстрация в терминале**

#### ➤ Покажите студентам результат следующих выражений:

```php
var_dump("5" == 5);    // true — приведение типа
var_dump("5" === 5);   // false — разные типы
var_dump(0 == "");     // true — оба приводятся к false
var_dump("abc" < "def"); // true — сравнение по алфавиту
var_dump(2 <=> 2);     // 0
var_dump(1 <=> 2);     // -1
```

#### ➤ Упражнение "Что будет выведено?"

```php
$a = false || true;
$b = false or true;

var_dump($a); // ?
var_dump($b); // ?
```

**Ожидаемый результат:**

```
$a = true      // потому что `false || true` сразу считается, и результат присваивается в $a
$b = false     // потому что `=` выше `or` по приоритету: сначала `$b = false`, а потом `or true` игнорируется
```

#### ➤ Проверка понимания побитовых операторов:

```php
var_dump(5 & 3);  // 1 (101 & 011 = 001)
var_dump(5 | 3);  // 7 (101 | 011 = 111)
var_dump(5 ^ 3);  // 6 (101 ^ 011 = 110)
```
