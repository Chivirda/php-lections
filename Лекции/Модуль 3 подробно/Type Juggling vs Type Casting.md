
## 🕒 0:25–0:35 — Type Juggling vs Type Casting

_Понимание работы с типами данных в PHP критично для написания предсказуемого, стабильного кода._

---

## 🔄 Часть 1: **Type Juggling (неявное приведение типов)**

### 📌 Что это такое?

**Type Juggling** — это автоматическое (неявное) преобразование типов PHP в момент выполнения, когда переменные разных типов участвуют в выражении.

PHP — язык с _динамической и слабо выраженной типизацией_. Это означает, что:

- переменная не привязана жёстко к одному типу,
- тип может автоматически измениться в зависимости от контекста.

---

### 🔧 Примеры:

```php
$a = "5" * 2;   // 10, "5" → int(5)
$b = "10 little pigs" + 5; // 15, строка начинается с числа
$c = "abc" * 2; // 0, нет чисел в начале строки
$d = 1 + true;  // 2, true → int(1)
```

---

### ⚠️ Подводные камни:

```php
var_dump("5 cats" == 5); // true
var_dump("0" == false);  // true
var_dump([] == false);   // true
```

Из-за таких особенностей код может вести себя **непредсказуемо**, особенно в проверках условий.

---

## 🧪 Демонстрация: угадай результат

Показать на экране:

```php
var_dump("5" == 5);
var_dump("5" === 5);
var_dump("abc" * 2);
var_dump(0 == "");        // true
var_dump([] == false);    // true
```

**Обсуждение:**  
Попросить студентов объяснить, почему `==` может давать неожиданные результаты.  
Перейти к обсуждению **type casting**, чтобы объяснить, как избежать этих ловушек.

## 🎯 Часть 2: **Type Casting (явное приведение типов)**

### 📌 Что это такое?

**Type Casting** — это **явное** указание, к какому типу нужно привести значение.  
Это способ взять контроль над поведением типов и избежать неожиданных автоматических преобразований.

---

### 🧱 Основной синтаксис:

```php
(int)   — привести к целому числу
(float) — к числу с плавающей точкой
(bool)  — к булеву
(string)— к строке
(array) — к массиву
(object)— к объекту
```

---

### 🧪 Примеры:

```php
$a = (int)"123abc";   // 123 — обрезается по первому нецифровому символу
$b = (bool)[];        // false — пустой массив приводится к false
$c = (string)true;    // "1"
$d = (int)false;      // 0
```

```php
var_dump((int)"42 apples");    // 42
var_dump((float)"3.14abc");    // 3.14
var_dump((bool)"0");           // false
var_dump((bool)"any text");    // true
```

## 🛡️ Часть 3: **Жёсткая типизация с `strict_types`**

### 📌 По умолчанию:

PHP **не** применяет строгую типизацию. Если вы укажете, что функция принимает `int`, но передадите `"5"`, PHP преобразует `"5"` → `5`.

---

### ✳️ Включение строгой типизации:

```php
declare(strict_types=1);
```

> **Важно:** строка должна стоять **первой** в файле — до `namespace`, `use`, `require`, и т.д.

---

### 🎯 Пример:

```php
declare(strict_types=1);

function add(int $a, int $b): int {
    return $a + $b;
}

echo add("5", 3); // Fatal error при включенном strict_types
```

### ⚠️ Без strict_types:

```php
function add(int $a, int $b): int {
    return $a + $b;
}

echo add("5", 3); // Работает, PHP сам преобразует строку в число
```

---

## 💡 Когда использовать strict_types?

- При работе в больших проектах или с командами.
- Для API и библиотек, где важно чёткое соблюдение контрактов.
- Для избежания багов, связанных с неочевидным приведением типов.
