
## 🧩 **Тема:** Работа со строками

> **Цель:** Понять, как в PHP работают строки, чем отличаются функции для Юникода, как использовать шаблоны, и зачем нужны Heredoc и Nowdoc.

---

### 🔤 1. Юникод и функции `mb_*`

#### ❗ Проблема:

В PHP строка — это просто последовательность байтов. Это значит, что стандартные функции работают с байтами, а не с символами. Например:

```php
echo strlen("Привет"); // вернёт 12, а не 6!
```

Почему? Потому что каждая кириллическая буква в UTF-8 занимает 2 байта.

#### ✅ Решение:

Используем многобайтовые функции из расширения **mbstring**:

```php
echo mb_strlen("Привет"); // 6
echo mb_substr("Привет, мир", 8); // мир
```

> ⚠ Убедитесь, что `mbstring` включён в `php.ini`.

#### 🛠 Практика:

Сравните `strlen("мама")` и `mb_strlen("мама")`.

### 🔗 2. Шаблоны (интерполяция) vs конкатенация

#### 📎 Конкатенация (склеивание строк):

```php
$name = "Алиса";
echo 'Привет, ' . $name . '!';
// Привет, Алиса!
```

Недостатки:

- дольше писать
- больше символов
- труднее читать при вложенных конструкциях

#### 🔄 Интерполяция (подстановка переменных в строку):

```php
echo "Привет, $name!";
// Привет, Алиса!
```

##### Когда использовать:

- Всегда, когда строка в **двойных кавычках**
- Также работает с **Heredoc**
- Можно подставлять вложенные свойства:

```php
echo "Ваш ID: {$user->id}";
```

> 💡 Фигурные скобки — обязательны, если переменная сложная или соседствует с буквами.

### 📝 3. Heredoc и Nowdoc

#### 📌 Heredoc:

Позволяет писать многострочные строки, как будто это отдельный блок текста.

```php
$name = "Алиса";
$message = <<<HTML
<h1>Привет, $name!</h1>
<p>Добро пожаловать на сайт.</p>
HTML;

echo $message;
```

- Поддерживает интерполяцию переменных
- Отлично подходит для HTML, SQL-запросов, шаблонов

#### 📌 Nowdoc:

Аналогичен **одинарным кавычкам** — переменные не подставляются.

```php
$name = "Алиса";
$message = <<<'TEXT'
Привет, $name!
TEXT;

echo $message; // выведет: Привет, $name!
```

> 🔎 Отличие в кавычках: Heredoc — `<<<HTML`, Nowdoc — `<<<'TEXT'`

---

### 🔧 Пример объединения:

```php
$user = (object)['id' => 42, 'name' => 'Иван'];

$html = <<<HTML
<div>
  <h2>Добро пожаловать, {$user->name}!</h2>
  <p>Ваш ID: {$user->id}</p>
</div>
HTML;

echo $html;
```

### 📚 Итоги

|Подход|Особенности|
|---|---|
|`mb_*`|Работают с Юникодом|
|Интерполяция|Читаемо, удобно, безопасно|
|Конкатенация|Подходит для склеивания значений, но менее читабельна|
|Heredoc|Многострочные шаблоны с подстановкой|
|Nowdoc|То же, но без подстановки переменных|
