
## 🕒 0:00–0:15 — Скалярные типы

PHP имеет 4 базовых скалярных типа:

1. `int` (целые числа)
2. `float` (числа с плавающей точкой)
3. `string` (строки)
4. `bool` (логический тип)

- `null` как особое значение (отсутствие значения)

---

### 🧮 `int` — целые числа

**Описание:**  
Это любые целые числа в пределах допустимого диапазона, зависящего от разрядности платформы:

- 32-битная система: от -2,147,483,648 до 2,147,483,647
- 64-битная система: от -9,223,372,036,854,775,808 до 9,223,372,036,854,775,807

**Примеры:**

```php
$a = 42;
$b = -17;
$c = 0;
```

**Особенности:**

- Деление `int / int` может вернуть `float`, если результат нецелый:
```php
echo 5 / 2; // 2.5
```

---

### 🔢 `float` — числа с плавающей точкой

**Описание:**  
Тип `float` (или double) — это числа с десятичной точкой или в экспоненциальной форме.

**Примеры:**

```php
$a = 3.14;
$b = 1.2e3;  // 1200
$c = 7E-10;  // 0.0000000007
```

**IEEE 754 и потери точности:**  
Числа с плавающей точкой представляются не точно. Например:

```php
echo 0.1 + 0.2 == 0.3 ? 'true' : 'false'; // false
var_dump(0.1 + 0.2); // float(0.30000000000000004)
```

**Почему это важно:**

- Нельзя использовать `==` для сравнения `float`. Лучше использовать:
```php
abs($a - $b) < 0.00001
```

---

### 🧵 `string` — строки

**Описание:**  
Тип для представления текста. Поддержка Unicode в виде байтовой строки (UTF-8 и т.д.).

#### Разные синтаксисы:

1. **Одинарные кавычки `'...'`**
    
    - Интерпретируются буквально.
    - Экранируются только `\\` и `\'`.
    
```php
$name = 'John';
echo 'Hello, $name'; // Hello, $name
```

2. **Двойные кавычки `"..."`**

    - Поддерживают **интерполяцию** переменных и спецсимволы (`\n`, `\t`, и т.д.).


```php
$name = 'John';
echo "Hello, $name"; // Hello, John
```

3. **heredoc**

    - Аналог двойных кавычек.
    - Удобен для многострочного текста.
   
```php
$name = 'Alice';
echo <<<TEXT
Привет, $name!
Добро пожаловать!
TEXT;
```

4. **nowdoc**

    - Аналог одинарных кавычек, интерполяция не происходит.


```php
$name = 'Alice';
echo <<<'TEXT'
Привет, $name!
TEXT;
```

**Конкатенация строк:**

```php
echo "Hello " . "world"; // Hello world
```

### ✅ `bool` — логический тип

**Значения:**

- `true`
- `false`

**Автоматическое приведение:**

- `false`: 0, 0.0, `"0"`, `""`, `null`, `[]`
- `true`: всё остальное

**Примеры:**

```php
$a = true;
$b = false;

var_dump((bool)0);     // false
var_dump((bool)123);   // true
var_dump((bool)"");    // false
var_dump((bool)"0");   // false
var_dump((bool)"abc"); // true
```

---

### ❌ `null` — отсутствие значения

**Описание:**  
`null` означает, что переменная не содержит никакого значения.

**Примеры:**

```php
$a = null;

$b = 5;
unset($b);  // теперь $b не определена
```

**Типичное использование:**

- В базе данных `null` = «значение неизвестно»
- При отсутствии аргумента в функции:
```php
function greet(?string $name) {
	if ($name === null) {
        echo "Hello, guest!";
	} else {
        echo "Hello, $name!";
	}
}
```

### 🧠 Интерактивное задание

**Вопрос студентам:**

```php
echo 0.1 + 0.2 == 0.3 ? 'true' : 'false';
```

**Ожидаемая реакция:**  
Многие ответят "true", но будет `false`.  
Объяснение основано на _ошибке округления в float_.

**Второе упражнение:**

```php
var_dump("5" == 5);     // true
var_dump("5" === 5);    // false
var_dump((bool)"0");    // false
var_dump((bool)"false");// true
```
