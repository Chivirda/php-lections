
## 🔄 1:35–1:40 — Плавный переход к следующей теме: **условные операторы и логика**

> **Цель:** Связать работу с типами (строки, числа, дата, enum) с **логическими проверками**, показать, зачем нужен `bool`.

---

### 📎 Мотивация:

PHP — слабо типизированный язык. Почти любой тип можно привести к логическому (`bool`) контексту:

```php
if ("")         → false
if ("0")        → false (!!)
if ("hello")    → true
if ([])         → false
if (["x"])      → true
if (0)          → false
```

#### ⚠ Опасный момент:

```php
if ("0") echo "ДА"; // ❌ ничего не выведет, потому что "0" → false
```

---

### 🔍 Что мы подведём к следующему блоку:

- Как PHP **интерпретирует значения** в условных выражениях?
- Что такое **truthy / falsy**?
- Как сравнение работает для enum?
- Как избежать ошибок при проверке значений (особенно в API, шаблонах и БД)?

---

### 📚 Переходный пример:

```php
$status = OrderStatus::Shipped;

if ($status === OrderStatus::Shipped) {
    echo "Заказ уже отправлен";
}
```

→ Здесь работает строгое сравнение `===`, потому что `$status` — объект enum.
