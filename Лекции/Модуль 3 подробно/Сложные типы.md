
## 🕒 0:35–0:45 — Сложные типы данных в PHP

В отличие от скалярных, **сложные типы** в PHP позволяют хранить коллекции, структуры и ссылки на действия. Они часто используются при работе с массивами, объектами, итерациями, функциями и динамической типизацией.

---

## 🔶 1. `array` — массив

### 📌 Что это такое?

Массив в PHP — это структура, объединяющая как **списки**, так и **ассоциативные словари**. Это на самом деле **упорядоченная хеш-таблица**, где каждый элемент имеет ключ и значение.

### 🧱 Виды:

#### ➊ Индексный массив

Ключи — целые числа, начинаются с 0.

```php
$colors = ["red", "green", "blue"];
echo $colors[1]; // green
```

#### ➋ Ассоциативный массив

Ключи — строки.

```php
$user = [
    "name" => "Alice",
    "age" => 30
];
echo $user["name"]; // Alice
```

#### ➌ Смешанный массив

Можно использовать одновременно числовые и строковые ключи.

```php
$data = [
    "first" => "A",
    1 => "B",
    2 => "C",
    "last" => "Z"
];
```

### 🔧 Работа с массивами:

- `count($array)` — количество элементов
- `array_keys($array)` — получить все ключи
- `in_array($val, $array)` — проверить, есть ли значение

### ⚠️ Подводные камни:

```php
$arr = [];
$arr["08"] = "zero-eight";
echo $arr[8]; // zero-eight, строка "08" стала числом!
```

> Приведение строковых чисел с ведущим нулём может неожиданно изменить ключ.

## 🔷 2. `object` — объект

### 📌 Что это такое?

Объекты — это экземпляры классов. Используются для хранения логики и состояния в ООП.

### 🧱 Пример:

```php
class User {
    public string $name;
    public int $age;
}

$u = new User();
$u->name = "Tom";
$u->age = 25;

echo $u->name; // Tom
```

Объекты хранятся по ссылке, а не копируются по значению.

---

### ➕ Дополнительные возможности:

- Объекты можно преобразовать из массива:
```php
$obj = (object)["x" => 10, "y" => 20];
echo $obj->x; // 10
```

- Можно проверять наличие свойств: `property_exists($obj, "x")`

## 🔶 3. `iterable` — итерируемый тип

### 📌 Что это такое?

Специальный псевдотип, объединяющий:

- `array`
- объекты, реализующие интерфейс `Traversable` (`Iterator`, `Generator` и т.д.)

### 🧱 Пример:

```php
function printItems(iterable $items) {
    foreach ($items as $item) {
        echo $item . PHP_EOL;
    }
}

printItems(["a", "b", "c"]);
```

Можно передать как массив, так и генератор:

```php
function gen() {
    yield "a";
    yield "b";
}
printItems(gen());
```

> Позволяет писать **гибкие и обобщённые функции**, принимающие «что-то перебираемое».

## 🔷 4. `callable` — вызываемое значение

### 📌 Что это такое?

Это переменная, которая **ссылается на функцию, метод или замыкание**, и может быть вызвана как функция.

### 🧱 Примеры:

#### ➊ Имя функции:

```php
function greet($name) {
    return "Hello, $name!";
}

$fn = 'greet';
echo $fn("Alice"); // Hello, Alice!
```

#### ➋ Анонимная функция (closure):

```php
$sayHi = function($name) {
    return "Hi, $name!";
};

echo $sayHi("Tom"); // Hi, Tom!
```

#### ➌ Метод объекта:

```php
class Greeter {
    public function hello($name) {
        return "Hi, $name";
    }
}

$g = new Greeter();
$callable = [$g, "hello"];
echo call_user_func($callable, "Anna"); // Hi, Anna
```

## 🔶 5. Объединённые и пересекающиеся типы (PHP 8+)

### 🔸 Union types (объединённые типы)

```php
function foo(int|string $x): void {
    echo $x;
}
```

— Аргумент может быть либо `int`, либо `string`.

### 🔹 Intersection types (пересекающиеся типы)

```php
function bar(A&B $obj) { ... }
```

— `$obj` должен реализовать **оба** интерфейса `A` и `B`.

## 💡 Интерактив: угадай результат

Показать и обсудить:

```php
$arr = [1, "a" => 2, 3 => "three"];
var_dump($arr);

$obj = (object)["a" => 1, "b" => 2];
var_dump($obj->a);

$fn = fn($x) => $x * 2;
echo $fn(5); // ?
```

**Объяснение:**

- Массив — комбинация ключей.
- Объект-преобразование.
- Стрелочные функции (`fn`) — короткий синтаксис для замыканий (PHP 7.4+).

## 📝 Заключение

|Тип|Назначение|
|---|---|
|`array`|Набор значений с ключами|
|`object`|Экземпляр класса, структура с поведением|
|`iterable`|Всё, что можно перебирать в `foreach`|
|`callable`|Всё, что можно вызвать как функцию|
|`mixed`|(PHP 8) любой тип|
|`union`|значение должно быть одного из указанных|
|`intersection`|значение должно удовлетворять нескольким типам|
