
## 📚 Модуль 2 — Лекция 1

### ⏱ 0:35–0:45 — Первая программа на PHP

---

### 🎯 Цель:

Научить студентов писать и запускать простейшую программу на PHP, освоить два способа запуска: через браузер и через командную строку (CLI). Понять отличия в поведении окружения при запуске.

---

## 📁 Шаг 1: Создание файла `hello.php`

1. Откройте текстовый редактор (например, VS Code, Notepad++, Sublime Text).
2. Создайте новый файл и сохраните его как `hello.php` в корневую директорию веб-сервера:
    - В XAMPP: `htdocs/hello.php`
    - В Docker: та папка, что смонтирована в `/var/www/html`
    - Если используете встроенный сервер: любая рабочая папка
3. Вставьте код:

```php
<?php
echo "Привет, мир!";
```

📌 **Обратите внимание:** PHP-код должен начинаться с `<?php`. Закрывающий тег `?>` можно опустить в чистых PHP-скриптах (это хорошая практика, чтобы избежать случайного вывода пробелов или символов).

---

## 🚀 Шаг 2: Запуск в браузере

**Как это работает:**

- PHP-код передаётся веб-серверу (Apache, встроенный сервер или контейнер с Apache).
- Сервер обрабатывает `.php` файл, выполняет код и возвращает **результат выполнения** (а не сам код) браузеру.

**Пример:**

- Откройте браузер и введите:
```
http://localhost/hello.php
```
- Вы увидите:
```
Привет, мир!
```

🧠 **Что происходит на сервере:**

- Apache вызывает интерпретатор PHP;
- PHP исполняет код и возвращает результат через stdout;
- Apache передаёт результат браузеру как HTML-ответ.

---

## 🖥 Шаг 3: Запуск в командной строке (CLI)

PHP можно запускать как скриптовый язык из терминала, без веб-сервера:

```bash
php hello.php
```

📌 Вывод в терминале будет точно таким же:

```
Привет, мир!
```

---

## 🔍 Сравнение: браузер vs CLI

|Критерий|В браузере (`http://localhost/hello.php`)|В CLI (`php hello.php`)|
|---|---|---|
|Запуск через веб-сервер|✅ Да|❌ Нет (запуск напрямую)|
|Доступны суперглобалы|✅ `$_GET`, `$_POST`, `$_SERVER` и др.|❌ Только `$_SERVER['argv']`|
|Использование HTML/шаблонов|✅ Да, может встраиваться в HTML|❌ Нет, вывод — только текст|
|Назначение|Веб-приложения|Скрипты, задачи, парсеры и т. п.|

---

## 📌 Пример различия: использование `$_GET`

В браузере можно передать параметры через URL:

```
http://localhost/hello.php?name=Иван
```

Добавим код в файл:

```php
<?php
$name = $_GET['name'] ?? 'гость';
echo "Привет, $name!";
```

📌 При заходе по ссылке:

```
http://localhost/hello.php?name=Иван
```

Результат:

```
Привет, Иван!
```

🧨 Но в CLI этот код **не сработает** — переменная `$_GET['name']` будет **неопределена**, так как CLI не обрабатывает параметры URL.

---

## 🛑 Частые ошибки начинающих:

- ❌ Открывают `.php` файл в браузере как `file://` → видят код, а не результат.
- ❌ Пишут PHP-код без открывающего тега `<?php`.
- ❌ Путают запуск через CLI и браузер.
- ❌ Ждут, что `$_GET` или `$_POST` будут работать в CLI (а это не так).

---

## 📎 Заключение

Первая программа:

```php
<?php
echo "Привет, мир!";
```

Может запускаться:

- Через браузер — в контексте веб-сервера;
- Через CLI — как консольная утилита.

Они оба важны: браузерный запуск для веб-приложений, CLI — для утилит, тестов, cron-скриптов.
