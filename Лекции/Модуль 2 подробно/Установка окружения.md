### 🧩 Варианты установки окружения

---

### **🔧 Вариант 1: XAMPP / MAMP**

**Что это?**  
XAMPP и MAMP — это готовые сборки, включающие:

- веб-сервер Apache;
- интерпретатор PHP;
- СУБД MySQL (MariaDB);
- панель управления сервисами.

**Подходит для:**

- начинающих пользователей;
- тех, кто хочет быстро начать без настройки вручную.

**📥 Установка:**

- Сайт для загрузки XAMPP: [https://www.apachefriends.org/index.html](https://www.apachefriends.org/index.html)
- Сайт для загрузки MAMP (macOS): [https://www.mamp.info/en/](https://www.mamp.info/en/)

**📂 Структура:**  
После установки:

- `htdocs/` — папка, в которую нужно помещать PHP-файлы.
- Панель управления позволяет запускать/останавливать Apache и MySQL.

**📌 Пример:**

1. Открыть `htdocs/` и создать файл `hello.php`:
```php
<?php echo "Привет, мир!"; ?>
```

2. Открыть в браузере: `http://localhost/hello.php`

### **🐳 Вариант 2: Docker (контейнер с php:8.3-apache)**

**Что это?**  
Контейнер — изолированная среда, где можно запускать PHP с Apache без установки на систему.

**Плюсы:**

- Не засоряет систему;
- Удобно работать в команде;
- Легко менять версию PHP, Apache, конфигурации.

**📥 Требования:**

- Установленный Docker: [https://www.docker.com/products/docker-desktop/](https://www.docker.com/products/docker-desktop/)

**📦 Команда для запуска:**

```bash
docker run -d -p 8080:80 -v ${PWD}:/var/www/html php:8.3-apache
```

**Разбор команды:**

- `-d` — запуск в фоновом режиме (detached mode)
- `-p 8080:80` — проксирование порта: локальный 8080 → контейнерный 80 (Apache)
- `-v ${PWD}:/var/www/html` — подключение текущей папки к веб-корню контейнера
- `php:8.3-apache` — официальный образ PHP с Apache

**📌 Пример:**

1. Создайте файл `index.php` в текущей директории:
```php
<?php echo "Hello from Docker!"; ?>
```

2. Откройте браузер: `http://localhost:8080/`


**📎 Как остановить контейнер:**

```bash
docker ps         # посмотреть ID контейнера
docker stop <ID>  # остановить
```

**💡 Советы:**

- Можно использовать `docker-compose.yml` для сложных проектов.
- Можно монтировать отдельную папку `src/`.

### **🌐 Вариант 3: Встроенный сервер PHP**

**Что это?**  
С версии PHP 5.4 встроен простой веб-сервер, который запускается одной командой — идеально для локальной разработки и отладки.

**📥 Установка:**

- Достаточно установить PHP ([https://www.php.net/downloads.php](https://www.php.net/downloads.php)).
- В Linux и macOS PHP часто уже установлен.

**📦 Запуск:**

```bash
php -S localhost:8000
```

**📌 Пример:**

1. В той же директории создайте `index.php`:
```php
<?php echo "Запущено через встроенный сервер!"; ?>
```

2. Запустите сервер:

```bash
php -S localhost:8000
```

3. Перейдите в браузере: `http://localhost:8000`


**📝 Особенности:**

- Работает только в одном каталоге.
- Не подходит для продакшена.
- Нет поддержки .htaccess.
