## 🧠 Краткое повторение пройденного

### ✅ В 1-м академическом часе:

1. **Установка окружения**:
    - XAMPP / MAMP — для быстрого старта.
    - Docker с `php:8.3-apache` — для продвинутых.
    - Встроенный сервер `php -S` — для тестов.
2. **Composer**:
    - `composer init` — инициализация проекта.
    - Подключение библиотек (Monolog).
    - Автозагрузка через PSR-4.
3. **PHP-теги**:
    - `<?php ... ?>` — стандарт.
    - `<?= ... ?>` — для вывода.
    - `<? ... ?>` — **не использовать**.
4. **Первая программа**:
    - `hello.php`: `echo "Привет, мир!";`
    - Запуск в браузере и CLI — сравнение.

---

### ✅ Во 2-м академическом часе:

1. **Синтаксис и переменные**:
    - Именование (`$camelCase`), область видимости (`global`, `static`), динамические переменные (`$$name`), суперглобалы (`$_GET`, `$_POST`, `$_SESSION`).
2. **Типы данных**:
    - Скалярные: `int`, `float`, `string`, `bool`.
    - Составные: `array`, `object`.
    - Специальные: `callable`, `iterable`, `null`.
    - Новые: `mixed`, `int|string`.
3. **Type Juggling**:
    - Автоматическое приведение типов.
    - Разница между `==` и `===`.
    - Подводные камни: `"0" == false`, `"" == 0`, и т.п.

### 📄 **Часть 2 — Короткие задания**

#### 🔹 `info.php`

- Вывести информацию о PHP с помощью `phpinfo()`.
- Убедиться, что файл открывается в браузере.

#### 🔹 `index.php`

- Получать параметр `name` через `$_GET`.
- Выводить:
```php
Привет, <имя>!
```

- Пример URL:
   
```
http://localhost/index.php?name=Катя
```


#### 🔹 `form.php`

- Сделать HTML-форму с полями:
    - `name` (текст)
    - `age` (число)

- При отправке формы POST-запросом:
    - вывести имя и возраст;
    - определить типы через `var_dump`.

### 📦 **Часть 3 — Composer + Monolog**

    - Настройте логгер Monolog.
