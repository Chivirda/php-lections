## 🤔 Что такое **type juggling**?

**Type juggling** (буквально: «жонглирование типами») — это механизм, при котором PHP **автоматически преобразует один тип данных в другой** в зависимости от контекста (арифметика, логика, сравнение и т.д.).

📌 Особенно важно: PHP делает это **автоматически и не всегда очевидно**.

---

## 🔍 Примеры, которые нужно показать в реальном времени (live coding)

### 📦 Пример 1: Строка + число

```php
$a = "5";
$b = 2;

var_dump($a + $b);  // int(7)
```

**Объяснение:**  
Строка `"5"` автоматически преобразуется в `int` → `5 + 2 = 7`

---

### ❗ Пример 2: сравнение строк и чисел

```php
var_dump("5" == 5);    // true
var_dump("5" === 5);   // false
```

**Объяснение:**

- `==` — сравнение **с приведением типов** → "5" становится числом.
- `===` — сравнение **без приведения типов** → типы не совпадают → `false`.

---

### ⚠️ Пример 3: неожиданные результаты

```php
var_dump(0 == "");      // true
var_dump(0 == "0");     // true
var_dump("0" == "");    // false
```

**Объяснение:**

- `""` → преобразуется в `0` при сравнении с числом.
- Но строка `"0"` ≠ пустая строка `""`.

---

### 💥 Пример 4: логические ловушки

```php
$password = "0";

if ($password) {
    echo "OK";
} else {
    echo "FAIL";
}
```

**Результат:** `FAIL`

**Почему?**

- В логическом контексте `"0"` → `false` (исключение из правила: непустая строка обычно true).
- Это частая ошибка: пароль `"0"` (например, PIN-код) отбрасывается как "пустой".

---

### ✅ Пример 5: безопасное сравнение (рекомендуется)

```php
$input = $_GET['age'] ?? null;

if ($input === "18") {
    echo "Ровно 18 лет";
}
```

📌 Строгое сравнение защищает от ошибок приведения типа.

---

## 🛡 Как избежать проблем с type juggling

|Плохая практика|Лучшая альтернатива|
|---|---|
|`$a == $b`|`$a === $b`|
|`$a != $b`|`$a !== $b`|
|`if ($var)`|`if (!empty($var))` или `isset($var)`|
|Обработка чисел из строки без фильтрации|`filter_var($value, FILTER_VALIDATE_INT)`|

|---|---|
