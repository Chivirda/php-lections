
## 📚 Модуль 2 — Лекция 1

### ⏱ 0:10–0:20 — Composer: управление зависимостями и автозагрузка

---

### 🎯 Цель:

Познакомить студентов с инструментом **Composer**, показать:

- как инициализировать PHP-проект;
- как подключать сторонние библиотеки;
- как работает автозагрузка классов по стандарту **PSR-4**;
- как использовать сторонний пакет (на примере **Monolog**).

---

## 🛠 Что такое Composer?

Composer — это **менеджер зависимостей** для PHP. Он позволяет:

- Подключать сторонние библиотеки;
- Автоматически загружать классы;
- Управлять версиями пакетов;
- Использовать автозагрузку по PSR-4 (автоматическое подключение классов по пространствам имён).

---

## 📦 Шаг 1: Инициализация проекта

1. Откройте терминал и перейдите в рабочую директорию:
```bash
mkdir my_project && cd my_project
```

2. Выполните команду:

```bash
composer init
```

3. Composer задаст серию вопросов:
	- Название пакета (например, `student/hello-world`);
	- Описание;
	- Автор;
	- Минимальная версия PHP;
	- Зависимости (можно пропустить и добавить позже);
	- Автозагрузка (укажем ниже вручную).
4. После выполнения создаётся файл `composer.json`.

---

## 🧩 Структура composer.json

Пример файла `composer.json` с автозагрузкой:

```json
{
  "name": "student/hello-world",
  "description": "Простой учебный проект на PHP",
  "type": "project",
  "require": {},
  "autoload": {
    "psr-4": {
      "App\\": "src/"
    }
  }
}
```

📌 **PSR-4** указывает: все классы с пространством имён `App\` будут искаться в папке `src/`.

---

## 🧱 Шаг 2: Настройка структуры проекта

Создайте структуру проекта:

```bash
mkdir src
touch src/Example.php
```

Пример содержимого `src/Example.php`:

```php
<?php

namespace App;

class Example {
    public function sayHello() {
        return "Привет из PSR-4!";
    }
}
```

---

## 🔃 Шаг 3: Обновление автозагрузки

После изменения `composer.json` необходимо сгенерировать автозагрузку:

```bash
composer dump-autoload
```

Composer создаст папку `vendor/` и файл `vendor/autoload.php`.

---

## 📚 Шаг 4: Использование стороннего пакета (Monolog)

Установим популярную библиотеку для логирования:

```bash
composer require monolog/monolog
```

Composer:

- скачает библиотеку в папку `vendor/`;
- добавит запись в `composer.json`:
```json
"require": {
    "monolog/monolog": "^3.0"
}
```


---

## 🧪 Шаг 5: Пример использования Monolog

Создайте файл `index.php`:

```php
<?php

require __DIR__ . '/vendor/autoload.php';

use Monolog\Logger;
use Monolog\Handler\StreamHandler;

// Создаём логгер с именем 'myLogger'
$log = new Logger('myLogger');

// Добавляем обработчик, который будет писать предупреждения в файл app.log
$log->pushHandler(new StreamHandler(__DIR__.'/app.log', Logger::WARNING));

// Пишем сообщение в лог
$log->warning('Это предупреждение!');
$log->error('Это ошибка!');
```

---

### 📁 Что происходит при запуске?

- Подключается файл `vendor/autoload.php`, созданный Composer — он автоматически "находит" нужные классы.
- Создаётся объект `Logger` из Monolog.
- Создаётся файл `app.log` и туда пишутся сообщения.

---

### 🧠 Почему это важно?

- Благодаря **Composer** вы больше не пишете `require` для каждого класса.
- Вы можете использовать тысячи готовых пакетов с [https://packagist.org/](https://packagist.org/).
- Автозагрузка делает архитектуру проекта чистой и масштабируемой.
