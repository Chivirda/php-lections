## 📌 Что такое переменная в PHP?

**Переменная** — это контейнер, в котором хранится значение.  
В PHP переменные обозначаются символом `$`.

### 📖 Синтаксис:

```php
$имя_переменной = значение;
```

Примеры:

```php
$name = "Алексей";
$age = 25;
$isStudent = true;
```

---

## ✍️ Правила именования переменных

### ✅ Допустимо:

- Имя начинается с `$`, за которым следует **буква или подчёркивание**, затем могут идти буквы, цифры и подчёркивания.
- Регистр имеет значение: `$userName` ≠ `$UserName`.

**Примеры:**

```php
$userName = "Игорь";   // правильно
$_data = [];           // правильно
$1user = "Ошибка";     // ❌ недопустимо
```

### 💡 Рекомендации:

- Используйте **camelCase**:
    - `$firstName`, `$totalAmount`

- Переменные должны быть осмысленными:
    - ❌ `$x`, `$a1`
    - ✅ `$userEmail`, `$cartItems`

## 🔒 Область видимости переменных

Переменные могут быть:

- **Локальными** (внутри функции);
- **Глобальными** (объявлены вне функции);
- **Статическими** (сохраняют значение между вызовами функции).

---

### 🧪 Пример 1: локальная и глобальная переменные

```php
$name = "Ирина"; // глобальная переменная

function sayHello() {
    // локальная переменная
    $name = "Алексей";
    echo "Привет, $name!";
}

sayHello();  // Привет, Алексей!
```

### 🧪 Пример 2: доступ к глобальной переменной внутри функции

```php
$greeting = "Добрый день";

function greet() {
    global $greeting;
    echo $greeting . ", студент!";
}

greet();  // Добрый день, студент!
```

---

### 🧪 Пример 3: статическая переменная

```php
function counter() {
    static $count = 0;
    $count++;
    echo $count . PHP_EOL;
}

counter();  // 1
counter();  // 2
counter();  // 3
```

## 💥 Динамические переменные

PHP позволяет использовать значение одной переменной как имя другой:

```php
$name = "username";
$username = "Иван";

echo $$name;  // Иван
```

🔍 В этом примере `$$name` = `$username`.

⚠️ Не злоупотребляйте динамическими переменными — они **снижают читаемость** кода.

## 🌐 Суперглобальные массивы

PHP содержит **предопределённые массивы**, доступные **всегда и везде**.

|Массив|Назначение|
|---|---|
|`$_GET`|данные из строки запроса (URL)|
|`$_POST`|данные из POST-запроса (формы)|
|`$_SERVER`|информация о сервере и окружении|
|`$_SESSION`|переменные сессии|
|`$_COOKIE`|данные cookie|
|`$_FILES`|загруженные файлы|
|`$_REQUEST`|объединяет `$_GET`, `$_POST`, `$_COOKIE`|

---

### 🧪 Пример: получение параметров из URL

Файл: `hello.php`

```php
<?php
$name = $_GET['name'] ?? 'гость';
echo "Привет, $name!";
```

URL:

```
http://localhost/hello.php?name=Мария
```

Результат:

```
Привет, Мария!
```

---

### 🧪 Пример: использование `$_POST`

Форма (HTML):

```html
<form method="post">
  <input type="text" name="city" />
  <button type="submit">Отправить</button>
</form>
```

PHP:

```php
<?php
$city = $_POST['city'] ?? '';
echo "Вы указали город: $city";
```

---

### 🧠 Примечания:

- Все суперглобалы — **массивы**.
- Они всегда доступны (глобальны).
- Для работы с `$_SESSION` нужно сначала вызвать:
```php
session_start();
```
