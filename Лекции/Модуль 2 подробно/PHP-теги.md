---

### 🎯 **Цель:**

Познакомить студентов с различными способами открытия PHP-кода, объяснить различия между тегами, важность настройки `short_open_tag`, и показать, какие формы следует использовать в современных проектах.

---

## 🔍 **Что такое PHP-теги?**

PHP — это встраиваемый язык программирования. Код PHP часто используется внутри HTML. Чтобы интерпретатор понимал, где начинается и заканчивается PHP-код, используются **теги PHP**.

---

## 🧩 **Типы PHP-тегов**

### 1. **Стандартный тег** — `<?php … ?>`

✅ **Рекомендуется и используется всегда.**  
Это основная и полностью поддерживаемая форма.

**Пример:**

```php
<?php
echo "Привет, мир!";
?>
```

**Особенности:**

- Работает во всех версиях PHP;
- Обязательно указывается полное `<?php`, чтобы код был совместим везде;
- Может использоваться в любых файлах `.php`.

---

### 2. **Сокращённый echo-тег** — `<?= … ?>`

✅ **Рекомендуется как удобное сокращение для вывода.**

Это сокращение:

```php
<?= $variable ?>
```

эквивалентно:

```php
<?php echo $variable; ?>
```

**Пример:**

```php
<html>
<body>
  <h1><?= "Заголовок страницы" ?></h1>
</body>
</html>
```

**Особенности:**

- Работает во всех поддерживаемых версиях PHP;
- Поддерживается всегда, независимо от настроек `php.ini`;
- Удобен в шаблонах (например, в `Blade`, `Twig`, `Smarty`, если поддерживается нативно).

---

### 3. **Устаревший короткий тег** — `<? … ?>`

❌ **Не рекомендуется!**  
Это _устаревший_ и ненадёжный способ. Пример:

```php
<? echo "Привет!"; ?>
```

**Почему не стоит использовать:**

- Эта форма **не работает**, если параметр `short_open_tag` в конфигурации `php.ini` выключен (по умолчанию **выключен** в большинстве современных окружений).
- Может не интерпретироваться как PHP-код, особенно в Unix-системах, где используется XML (конфликт с `<?xml`).

---

## ⚙️ **Настройка short_open_tag**

**Где искать:**  
Файл `php.ini` (основной конфигурационный файл PHP).

**Найти параметр:**

```ini
short_open_tag = Off
```

**Что означает:**

- `Off` — короткие теги `<?` НЕ работают (по умолчанию).
- `On` — короткие теги `<?` разрешены (НЕ рекомендуется включать).

**Как проверить текущую настройку:**  
Создайте файл `info.php`:

```php
<?php phpinfo(); ?>
```

И откройте его в браузере — найдите параметр `short_open_tag`.

---

## 💡 **Практические советы**

- **ВСЕГДА используйте `<?php` и `<?=`**. Они работают в любой конфигурации PHP.
- Если вы пишете код для CMS (например, WordPress, Joomla), всегда придерживайтесь совместимых тегов.
- Никогда не полагайтесь на `short_open_tag`, особенно в кросс-платформенной или командной разработке.

---

## 📁 Пример: правильный и неправильный код

✅ **Хорошо:**

```php
<?php
echo "Добро пожаловать!";
?>
```

✅ **Сокращённо:**

```php
<?= "Добро пожаловать!" ?>
```

❌ **Плохо:**

```php
<? echo "Добро пожаловать!"; ?>  // Не работает, если short_open_tag=Off
```
