## 🔠 Типы данных в PHP

В PHP переменная может **изменять тип во время выполнения**, что называется **динамической (или слабой) типизацией**.

### Основные группы:

|Группа|Типы данных|
|---|---|
|Скалярные|`int`, `float`, `bool`, `string`|
|Составные|`array`, `object`|
|Специальные|`null`, `callable`, `iterable`|
|Смешанные (PHP 8+)|`mixed`, `union types`|

---

## 🧮 1. Скалярные типы

### 🔢 `int` — целое число

```php
$age = 30;
```

### 🔣 `float` — число с плавающей точкой

```php
$price = 99.95;
```

### 🔁 `bool` — логическое значение

```php
$isActive = true;
```

### 🔤 `string` — строка

```php
$name = "Сергей";
```

---

## 🧰 2. Составные типы

### 📚 `array` — массив

```php
$colors = ["red", "green", "blue"];
```

### 🧱 `object` — объект

```php
class Person {
  public $name = "Иван";
}
$p = new Person();
echo $p->name;  // Иван
```

---

## 🧪 3. Специальные типы

### ❌ `null` — отсутствие значения

```php
$empty = null;
```

### 📞 `callable` — вызываемое значение (функция или метод)

```php
function greet() {
  echo "Привет!";
}

$func = 'greet';
$func(); // Вызов через переменную
```

### 🔁 `iterable` — итерируемый объект или массив (используется в `foreach`)

```php
function printAll(iterable $items) {
  foreach ($items as $item) {
    echo $item . PHP_EOL;
  }
}
```

---

## 🧬 4. Смешанные типы (PHP 8+)

### 🔄 `mixed` — может быть **любым** типом

```php
function doSomething(mixed $value) {
  var_dump($value);
}
```

### 🔀 `union types` — допускает **несколько** типов

```php
function setId(int|string $id) {
  echo "ID: $id";
}
```

📌 Синтаксис `int|string` означает, что аргумент может быть **либо** `int`, **либо** `string`.

---

## 🧪 Проверка типа

PHP предлагает функции для проверки типа:

|Проверка|Пример|
|---|---|
|`is_int($x)`|Проверяет, целое ли число|
|`is_string($x)`|Проверяет, строка ли|
|`is_array($x)`|Проверяет, массив ли|
|`is_object($x)`|Проверяет, объект ли|
|`is_callable($x)`|Проверяет, можно ли вызвать|
|`is_null($x)`|Проверяет, равно ли `null`|

---

## 🧠 Особенность: автоматическое приведение типов

PHP старается привести тип автоматически, если это возможно:

```php
$result = "5" + 10;  // 15
```

```php
var_dump("10" == 10);   // true
var_dump("10" === 10);  // false
```

⛔️ Это называется **type juggling**. Может быть источником неожиданных багов!

---

## 🧪 Демонстрация: слабая типизация

```php
var_dump("5" == 5);    // true — PHP приводит строку к числу
var_dump("5" === 5);   // false — разные типы: строка и число
```

---

## 🧠 Закрепление: типы данных и приведение

Пример:

```php
$val = "42";
echo $val + 1;        // 43 (строка преобразуется в число)
echo $val . 1;        // "421" (конкатенация строк)
```
