
## 🔹 0:00–0:10 — Установка Laravel. Структура каталогов

### 🎯 **Цель блока**

Познакомить студентов с установкой Laravel, первичным запуском проекта и структурой его каталогов.

---

### ✅ **Установка Laravel**

#### 📌 **Вариант 1: с помощью Composer**

> Composer — менеджер зависимостей PHP. Laravel устанавливается как готовый скелет-проект.

```bash
composer create-project laravel/laravel demo
```

После выполнения:

- Laravel будет установлен в папку `demo`.
- Все зависимости будут подтянуты автоматически.
- Будет сгенерирован `.env` файл и ключ приложения.

#### 📌 **Вариант 2: с помощью Laravel Installer**

> Устанавливается глобально один раз и ускоряет создание проектов.

```bash
composer global require laravel/installer
laravel new demo
```

> Убедитесь, что `~/.composer/vendor/bin` (или `%USERPROFILE%\AppData\Roaming\Composer\vendor\bin`) добавлен в `PATH`.

---

### ✅ **Первый запуск**

Перейдите в папку проекта и запустите локальный сервер:

```bash
cd demo
php artisan serve
```

Laravel доступен по адресу: `http://localhost:8000`

---

### 📁 **Структура каталогов Laravel**

|Каталог|Назначение|
|---|---|
|`app/`|Бизнес-логика, модели, сервисы, кастомные классы|
|`app/Http/Controllers/`|Контроллеры веб-приложения|
|`bootstrap/`|Начальная загрузка фреймворка, файл `app.php`|
|`config/`|Все конфигурационные файлы (`app.php`, `database.php`, и т.д.)|
|`database/`|Миграции, сидеры, фабрики данных|
|`public/`|Корневая директория веб-сервера. Содержит `index.php`|
|`resources/views/`|Blade-шаблоны|
|`resources/js/`, `resources/css/`|Фронтенд-ассеты|
|`routes/web.php`|Файл маршрутов веб-интерфейса|
|`storage/`|Кэш, сессии, логи, загруженные файлы|
|`tests/`|Модульные и функциональные тесты|
|`vendor/`|Все зависимости (не редактировать вручную)|

---

### 🧠 **Объяснение: зачем Laravel так устроен**

- Разделение по ответственности: легче поддерживать и масштабировать.
- Ясная структура для любого разработчика, знакомого с Laravel.
- Совместимость с Laravel-командами (Artisan), миграциями, автозагрузкой и контейнером зависимостей.

---

### 🛠 **Полезные команды на старте:**

```bash
php artisan list       # Все доступные команды
php artisan about      # Информация о Laravel
php artisan --version  # Текущая версия Laravel
```
