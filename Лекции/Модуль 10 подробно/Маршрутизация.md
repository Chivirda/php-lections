
## 🔹 0:10–0:20 — Маршрутизация (Routing)

### 🎯 **Цель блока**

Познакомить студентов с основами маршрутизации в Laravel: определение маршрутов, методы HTTP, параметры, возврат view или данных, привязка к контроллерам.

---

### 📁 **Где находятся маршруты?**

Все маршруты веб-интерфейса описываются в файле:

```
routes/web.php
```

Для API — в `routes/api.php`.

---

### 🧩 **Синтаксис базового маршрута**

```php
use Illuminate\Support\Facades\Route;

Route::get('/hello', function () {
    return 'Hello, world!';
});
```

- Первый аргумент: путь (`/hello`)
- Второй аргумент: callback-функция или контроллер

---

### 🧭 **Методы маршрутов**

|Метод|HTTP-метод|Описание|
|---|---|---|
|`Route::get()`|GET|Получение данных / страница|
|`Route::post()`|POST|Отправка формы|
|`Route::put()`|PUT|Обновление ресурса|
|`Route::delete()`|DELETE|Удаление ресурса|
|`Route::match(['get', 'post'], ...)`|Комбинированный||
|`Route::any()`|Любой метод||

---

### 🔡 **Маршруты с параметрами**

#### 📌 Обязательный параметр:

```php
Route::get('/hello/{name}', function ($name) {
    return "Привет, $name!";
});
```

Открытие `http://localhost:8000/hello/Sergey` выведет:

```
Привет, Sergey!
```

#### 📌 Необязательный параметр:

```php
Route::get('/user/{name?}', function ($name = 'Гость') {
    return "Привет, $name!";
});
```

---

### 🧰 **Передача параметров в контроллер**

```php
Route::get('/posts/{id}', [PostController::class, 'show']);
```

```php
// В контроллере:
public function show($id) {
    return "Post #$id";
}
```

---

### 📌 **Именованные маршруты (для ссылок)**

```php
Route::get('/dashboard', [DashboardController::class, 'index'])->name('dashboard');
```

```blade
<a href="{{ route('dashboard') }}">Перейти</a>
```

---

### 🖼 **Возврат view**

```php
Route::get('/welcome', function () {
    return view('welcome');
});
```

- Laravel автоматически ищет `resources/views/welcome.blade.php`.  

---

### 💡 **Полезные Artisan-команды:**

```bash
php artisan route:list    # Список всех маршрутов
php artisan route:clear   # Очистить кэш маршрутов
php artisan route:cache   # Кэшировать маршруты (в продакшене)
```

---

### 🧠 **Объяснение: зачем нужны маршруты?**

- Они соединяют **URL** с **логикой контроллера** или **view**.
- Упрощают структуру приложения.
- Обеспечивают гибкость: параметры, middleware, именование, ограничения (например, регулярки).

---

### 🧪 **Интерактивное задание:**

> "Создайте маршрут `/hello/{name}`, который будет возвращать страницу `hi.blade.php`, где будет выведено имя пользователя."

```php
Route::get('/hello/{name}', function ($name) {
    return view('hi', ['name' => $name]);
});
```

```blade
<!-- resources/views/hi.blade.php -->
<h1>Привет, {{ $name }}</h1>
```
