
## 🔹 2-й акад-час (0:12–0:22) — Миграции и сидеры

### 🎯 **Цель блока**

Научиться управлять структурой базы данных с помощью миграций и наполнять таблицы тестовыми данными с помощью сидеров.

---

## 🧩 Что такое миграции?

- **Миграции** — это версия базы данных в виде кода.
- Позволяют создавать, изменять и откатывать таблицы БД безопасно.
- В Laravel миграции — это обычные PHP-классы с методами `up()` и `down()`.

---

## ✅ Шаг 1: Создание миграции

```bash
php artisan make:migration create_posts_table
```

Пример с дополнительным полем:

```php
Schema::create('posts', function (Blueprint $table) {
    $table->id();
    $table->string('title');
    $table->text('body');
    $table->integer('views')->default(0);
    $table->timestamps();
});
```

### Применить миграции:

```bash
php artisan migrate
```

---

## ✅ Шаг 2: Откат миграции

Иногда нужно отменить последнее изменение:

```bash
php artisan migrate:rollback
```

Откатить на несколько шагов:

```bash
php artisan migrate:rollback --step=2
```

Откатить всё:

```bash
php artisan migrate:reset
```

---

## ✅ Шаг 3: Изменение таблицы (add column)

```bash
php artisan make:migration add_status_to_posts_table
```

В миграции:

```php
Schema::table('posts', function (Blueprint $table) {
    $table->string('status')->default('draft');
});
```

---

## 🧩 Что такое сидеры?

- **Сидеры** — это классы, которые наполняют базу тестовыми (или начальными) данными.
- Полезны для разработки, тестирования и начальной инициализации.

---

## ✅ Шаг 4: Создание сидера

```bash
php artisan make:seeder PostSeeder
```

Пример сидера:

```php
use App\Models\Post;
use Illuminate\Database\Seeder;

class PostSeeder extends Seeder
{
    public function run(): void
    {
        Post::create([
            'title' => 'Sample Post',
            'body' => 'This is a seeded post.',
        ]);

        Post::factory()->count(10)->create();  // Через фабрику
    }
}
```

Запуск:

```bash
php artisan db:seed --class=PostSeeder
```

Запустить все сидеры:

```bash
php artisan db:seed
```

---

## ✅ Шаг 5: Использование сидеров в DatabaseSeeder

Laravel по умолчанию использует `database/seeders/DatabaseSeeder.php` как "главный сидер".

```php
public function run(): void
{
    $this->call(PostSeeder::class);
}
```

Теперь можно просто:

```bash
php artisan db:seed
```

---

## ✅ Генерация данных через фабрики (Laravel >=8)

Фабрики создают фейковые данные.

```bash
php artisan make:factory PostFactory --model=Post
```

```php
use Illuminate\Database\Eloquent\Factories\Factory;

class PostFactory extends Factory
{
    public function definition(): array
    {
        return [
            'title' => fake()->sentence(),
            'body'  => fake()->paragraph(),
        ];
    }
}
```

И в сидере:

```php
Post::factory()->count(10)->create();
```

---

## 🧠 Почему миграции и сидеры важны?

|Миграции|Сидеры|
|---|---|
|Обеспечивают версионирование структуры БД|Позволяют автоматически наполнять БД данными|
|Легко откатываются|Полезны для тестирования|
|Независимы от среды (разработчики + продакшен)|Реплицируемые данные между разработчиками|
