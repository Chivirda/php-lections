
## **0:00–0:12 — Что считается «шаблоном»?**

### 🔹 **Цель блока:**

Понять, чем шаблон отличается от обычного PHP-файла с HTML, зачем нужны шаблонизаторы, какие они бывают и как работают.

---

### 🔸 **Что такое шаблон в веб-разработке?**

**Определение:**

> **Шаблон** — это файл, который содержит разметку (HTML) и специальные конструкции для подстановки данных. Он не содержит бизнес-логики, только представление.

**Пример до шаблона:**

```php
<h1>Привет, <?php echo $username; ?>!</h1>
```

**Пример с шаблоном (Blade):**

```blade
<h1>Привет, {{ $username }}!</h1>
```

---

### 🔸 **Зачем использовать шаблоны?**

1. ✅ **Разделение логики и представления**
    - Логика в контроллере, шаблон — только HTML и переменные.

2. ✅ **Упрощение поддержки**
    - Шаблоны проще читать и изменять.

3. ✅ **Безопасность**
    - Современные шаблонизаторы автоматически экранируют данные.


---

### 🔸 **Популярные шаблонизаторы и их особенности:**

|Шаблонизатор|Особенности|Где используется|
|---|---|---|
|**PHP-native**|Использование `include()` / `require()`. Простейшая форма, без защиты от XSS|В самописных проектах|
|**Blade**|Интегрирован в Laravel, поддерживает компоненты, `@section`, `@csrf`, `@foreach`, `@if`|Laravel|
|**Twig**|Чистый синтаксис, строгая типизация, автоэкранизация, фильтры|Symfony, Drupal|
|**Mustache**|Без логики (логика вне шаблона), кросс-языковой|JavaScript, Go, PHP|
|**Smarty**|Старая, но мощная система шаблонов, поддерживает кэширование, логику в шаблоне|Устаревшие или старые проекты|

---

### 🔸 **Концепции в шаблонизаторах:**

#### ✅ **Теги (Tags)**

Шаблонные конструкции, которые заменяются на значения:

```blade
{{ $name }}
{% if user %}
Hello, {{ user.name }}
{% endif %}
```

#### ✅ **Фильтры (Filters)**

Модификация вывода:

```twig
{{ name | upper }}
{{ price | number_format(2, '.', ' ') }}
```

#### ✅ **Блоки (Blocks)**

Наследование шаблонов — «шапка/подвал» отдельно, страницы — потомки:

```twig
{% extends "base.html.twig" %}
{% block content %}
    <h1>Hello!</h1>
{% endblock %}
```

Blade:

```blade
@extends('layouts.app')

@section('content')
    <h1>Hello</h1>
@endsection
```

---

### 🧪 Интерактив

**Примеры:**  
Показать один и тот же шаблон:

1. В обычном PHP (`include`)
2. В Blade (`@extends`, `@section`)
3. В Twig (`{% extends %}`, `{{ var }}`)

Спросить:

- Где читается проще?
- Где меньше логики?
- Что произойдёт, если переменная содержит `<script>`?

---

Вот два простых **live-кодинг примера**: один — на **Blade (Laravel)**, второй — на **Twig (Symfony или standalone)**. Каждый из них показывает:

- базовый шаблон `layout`,
- страницу-наследник с контентом,
- вывод переменной,
- как безопасно подставляется значение.

## ✅ **Пример 1: Blade (Laravel)**

### 📁 `resources/views/layouts/app.blade.php`

```blade
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>@yield('title', 'Мой сайт')</title>
</head>
<body>
    <header>
        <h1>Шапка сайта</h1>
    </header>

    <main>
        @yield('content')
    </main>

    <footer>
        <p>Футер</p>
    </footer>
</body>
</html>
```

---

### 📁 `resources/views/page.blade.php`

```blade
@extends('layouts.app')

@section('title', 'Приветствие')

@section('content')
    <h2>Привет, {{ $name }}!</h2>
    <p>Ваше сообщение: {{ $message }}</p>
@endsection
```

---

### 📁 `routes/web.php`

```php
use Illuminate\Support\Facades\Route;

Route::get('/', function () {
    return view('page', [
        'name' => 'Сергей',
        'message' => '<script>alert("XSS!")</script>',
    ]);
});
```

🛡️ **Результат:** вредоносный `<script>` экранируется и не выполнится.

## ✅ **Пример 2: Twig (Symfony или standalone)**

### 📁 `templates/base.html.twig`

```twig
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>{% block title %}Мой сайт{% endblock %}</title>
</head>
<body>
    <header>
        <h1>Шапка сайта</h1>
    </header>

    <main>
        {% block content %}{% endblock %}
    </main>

    <footer>
        <p>Футер</p>
    </footer>
</body>
</html>
```

---

### 📁 `templates/page.html.twig`

```twig
{% extends 'base.html.twig' %}

{% block title %}Приветствие{% endblock %}

{% block content %}
    <h2>Привет, {{ name }}!</h2>
    <p>Ваше сообщение: {{ message }}</p>
{% endblock %}
```

---

### 📁 Контроллер в Symfony (`src/Controller/DefaultController.php`)

```php
use Symfony\Bundle\FrameworkBundle\Controller\AbstractController;
use Symfony\Component\HttpFoundation\Response;
use Symfony\Component\Routing\Annotation\Route;

class DefaultController extends AbstractController
{
    #[Route('/', name: 'home')]
    public function index(): Response
    {
        return $this->render('page.html.twig', [
            'name' => 'Сергей',
            'message' => '<script>alert("XSS!")</script>',
        ]);
    }
}
```

🛡️ **Twig по умолчанию экранирует всё**, `<script>` не выполнится.
