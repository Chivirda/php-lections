### 🕒 0:00–0:15 — **[Скалярные типы](./Модуль%203%20подробно/Скалярные%20типы.md)**

**Ключевые пункты:**

- `int` — целые числа. Примеры: `1`, `-5`, `0`.
- `float` — числа с плавающей точкой. Хранятся по стандарту IEEE 754.
    - Важное поведение: `0.1 + 0.2 != 0.3` (см. ниже).
- `string` — строки.
    - Одинарные кавычки `'` — интерпретируются буквально.
    - Двойные кавычки `"` — интерполяция переменных: `"Hello, $name"`.
    - `heredoc` и `nowdoc`: удобны для многострочного текста.
        - `heredoc`: интерполяция как в двойных кавычках.
        - `nowdoc`: интерпретация как в одинарных кавычках.
- `bool` — `true` и `false`.
    - Преобразуются из других типов (например, `0`, `""`, `[]` → `false`).
- `null` — отсутствие значения.

**Интерактив:**

```php
echo 0.1 + 0.2 == 0.3 ? 'true' : 'false'; // Результат: false
```

Обсуждаем, почему результат «false» из-за особенностей хранения `float`.

Дополнительно:

```php
var_dump(0.1 + 0.2); // float(0.30000000000000004)
```

### 🕒 0:15–0:25 — **[Операторы](./Модуль%203%20подробно/Операторы.md)**

**Ключевые пункты:**

- **Арифметические:** `+`, `-`, `*`, `/`, `%`, `**`.
- **Строковые:** `.` — объединение строк: `"a" . "b" → "ab"`.
- **Логические:** `&&`, `||`, `!`, `and`, `or` (отличия по приоритету).
- **Побитовые:** `&`, `|`, `^`, `~`, `<<`, `>>`.
- **Сравнения:**
    - `==` — сравнение по значению (с приведением типов).
    - `===` — строгое сравнение (и тип, и значение должны совпадать).

**Интерактив:**  
Живой код в терминале:

```php
var_dump("5" == 5);   // true
var_dump("5" === 5);  // false
var_dump(true == 1);  // true
var_dump(true === 1); // false
var_dump("hello" . 5); // string(6) "hello5"
```

Объяснение разницы между `==` и `===`, визуальная проверка типов.

### 🕒 0:25–0:35 — **[Type Juggling vs Type Casting](./Модуль%203%20подробно/Type%20Juggling%20vs%20Type%20Casting.md)**

**Ключевые пункты:**

- **Type Juggling (неявное приведение):**  
    PHP старается «угадать» тип, когда работает с переменными разных типов.
```php
$a = "5" * 2; // 10
```
    Строка `"5"` будет приведена к `int`.
- **Type Casting (явное приведение):**
```php
$a = (int)"123abc"; // 123
$b = (bool)[];      // false
```

- **Жёсткая типизация:**
   
    - `declare(strict_types=1);` — запрещает неявное приведение типов.
    - Полезно в функциях, где важно, чтобы аргументы и возвращаемые значения строго соответствовали типу.

**Пример:**

```php
declare(strict_types=1);

function add(int $a, int $b): int {
    return $a + $b;
}

echo add("5", 2); // Fatal error при strict_types=1
```

### 🕒 0:35–0:45 — **[Сложные типы](./Модуль%203%20подробно/Сложные%20типы.md)**

**Ключевые пункты:**

- **array**
    - Индексный: `$a = [1, 2, 3];`
    - Ассоциативный: `$a = ['name' => 'Alice', 'age' => 30];`
    - Смешанный: возможны любые ключи.
- **object**
    
    - Пример:
```php
class User {
	public string $name;
}

$u = new User();
$u->name = "Tom";
```

- **iterable**
    
    - Тип данных, который можно перебирать в `foreach`. Поддерживает `array` и `Traversable`.

- **callable**

    - Ссылка на функцию/метод:

```php
function sayHi() { echo "Hi"; }
$f = 'sayHi';
$f(); // Вызовет sayHi
```

- **mixed**

    - Любой тип. Используется, когда тип заранее неизвестен.

- **Union Types:**

```php
function foo(int|string $value) { ... }
```

- **Intersection Types:**

```php
function bar(A&B $obj) { ... } // $obj должен реализовать оба интерфейса A и B
```

### ⏰ 0:50–1:00 — **[Работа со строками](./Модуль%203%20подробно/Работа%20со%20строками.md)**

#### 🔑 Ключевые понятия:

- **Юникод и функции `mb_*`**:
    
    - Строки в PHP — последовательность байтов. Стандартные функции (`strlen`, `substr`) не работают с многобайтовыми символами (например, кириллицей).
    - Используем `mb_strlen`, `mb_substr` и др.

	```php
	echo mb_strlen("Привет"); // 6
	```

- **Шаблоны (интерполяция) vs конкатенация**:
    
    - Интерполяция: `"Привет, $name!"`
    - Конкатенация: `'Привет, ' . $name . '!'`
    - Предпочтительна интерполяция: читабельнее и короче.
    - Вложенные переменные: `"Ваш ID: {$user->id}"`

- **Heredoc / Nowdoc**:
    
    - Heredoc — альтернатива кавычкам, поддерживает переменные.

```php
$text = <<<HTML
<p>Привет, $name!</p>
HTML;
```

    - Nowdoc — как одиночные кавычки, переменные не подставляются.

- **Blade-шаблоны**:
    - Laravel Blade использует синтаксис вроде `{{ $name }}` и `@if($user)`
    - Интерполяция безопаснее и понятнее, чем `echo` или `print`.

### ⏰ 1:00–1:15 — **[Дата и время](./Модуль%203%20подробно/Дата%20и%20время.md)**

#### 🔑 Ключевые понятия:

- **Класс `DateTime` и `DateTimeImmutable`**:
    
    - `DateTime` — объектная обёртка над датой и временем.
    - `DateTimeImmutable` — при изменении возвращает новый объект.
    
```php
$now = new DateTime();
$future = $now->modify('+1 day');
```

- **Часовой пояс**:
    
    - Всегда явно задавайте часовой пояс:

```php
date_default_timezone_set('Europe/Moscow');
```

- **Форматы вывода**:
    
    - `format()` для чтения:
    
```php
echo $now->format(DateTime::ATOM); // ISO-8601
```

    - Стандарты: ISO-8601 (`Y-m-d\TH:i:sP`) — рекомендуемый для API.

- **Константы**:
    
    - `const MY_CONST = 'value';`

    - Отличие: `define()` можно использовать вне классов, динамически.

- **Перечисления (enum) — PHP 8.1+**:
    
    - Простое перечисление:

```php
enum Status {
  case Pending;
  case Shipped;
  case Delivered;
}
```

- Скалярное перечисление:

```php
enum Role: string {
  case Admin = 'admin';
  case User = 'user';
}
```


#### 🧠 Интерактив: мини-квиз

**Вопрос:** Как лучше всего задать перечисление статусов заказа в современном PHP?

**Варианты:**

1. `const STATUS_PENDING = 1;`
2. `define('STATUS_PENDING', 1);`
3. `enum OrderStatus { case Pending; case Approved; case Cancelled; }`

**Обсуждение:**  
→ Лучший способ — enum, если используем PHP 8.1+. Он безопасен, читаем и расширяем.
