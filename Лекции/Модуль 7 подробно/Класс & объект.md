
## 🔹 0:00–0:15 — Класс & объект

### 📌 Цель блока:

Познакомить студентов с базовыми понятиями объектно-ориентированного программирования (ООП) в контексте PHP: что такое класс, объект, свойства и методы, а также синтаксис обращения через `$this` и `->`.

---

### 📖 Теория

#### 🧱 Класс

Класс — это шаблон (или "чертёж"), по которому создаются объекты. Он определяет **свойства** (переменные) и **методы** (функции), которыми будут обладать объекты.

Пример:

```php
class User {
    public $name;
    public $email;

    public function greet() {
        echo "Hello, my name is " . $this->name;
    }
}
```

#### 🔧 Объект

Объект — это экземпляр класса. Он создаётся с помощью ключевого слова `new`.

```php
$user = new User();
$user->name = "Alice";
$user->greet(); // Hello, my name is Alice
```

---

### 📎 Объяснение ключевых конструкций:

|Элемент|Назначение|
|---|---|
|`class`|Объявление класса|
|`$this`|Ссылка на текущий объект, используется внутри методов для доступа к свойствам/методам|
|`->`|Оператор доступа к свойствам/методам объекта|
|`new`|Создание нового экземпляра класса|

---

### 💡 Что важно понять:

- Класс сам по себе ничего не делает — он просто определяет структуру.
- Объекты — конкретные экземпляры, на которых можно вызывать методы и изменять свойства.
- `$this` используется внутри метода, чтобы получить доступ к текущему объекту.
- Можно создать сколько угодно объектов одного класса.

---

### 👨‍💻 Пример в коде:

```php
class Car {
    public $brand;
    public $color;

    public function describe() {
        echo "This car is a $this->color $this->brand.";
    }
}

$car1 = new Car();
$car1->brand = "Toyota";
$car1->color = "red";
$car1->describe(); // This car is a red Toyota.

$car2 = new Car();
$car2->brand = "Ford";
$car2->color = "blue";
$car2->describe(); // This car is a blue Ford.
```

#### Вопросы:

- Что такое класс и чем он отличается от объекта?
- Почему `$this` используется с `->`?
- Что произойдёт, если обратиться к неинициализированному свойству?

#### Упражнение:

Пусть студенты напишут класс `Person`, с полями `name` и `age`, и методом `introduce()`, который выводит фразу:

> "Меня зовут {name}, мне {age} лет."

Пример использования:

```php
$person = new Person();
$person->name = "Дмитрий";
$person->age = 30;
$person->introduce(); // Меня зовут Дмитрий, мне 30 лет.
```
