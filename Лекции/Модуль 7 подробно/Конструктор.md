
## 🔹 0:15–0:25 — **Конструктор**

### 📌 Цель блока:

Показать, как правильно инициализировать объект с помощью конструктора (`__construct`), какие бывают зависимости (обязательные и опциональные), и как упрощать создание объектов через параметры.

---

### 📖 Теория

#### 🔧 Что такое `__construct()`

Конструктор — это специальный метод, который автоматически вызывается при создании объекта.

```php
class User {
    public $name;

    public function __construct($name) {
        $this->name = $name;
    }
}
```

Теперь при создании объекта `User`, мы передаём имя:

```php
$user = new User("Alice");
echo $user->name; // Alice
```

#### 🔍 Зачем нужен:

- Упрощает инициализацию свойств.
- Обеспечивает обязательные значения при создании.
- Позволяет внедрять зависимости (например, сервисы или настройки).

---

### 🧩 Обязательные и опциональные зависимости

#### Обязательные аргументы

```php
class Product {
    public function __construct(
        public string $name,
        public float $price
    ) {}
}
$product = new Product("Книга", 300.0);
```

#### Опциональные аргументы

```php
class Product {
    public function __construct(
        public string $name,
        public float $price = 100.0
    ) {}
}
$product = new Product("Ручка"); // $price = 100.0 по умолчанию
```

Можно задавать `null` как дефолт:

```php
public function __construct(private ?Logger $logger = null) {}
```

---

### 🧠 Пояснение по типам зависимостей

|Тип зависимости|Пример|Примечание|
|---|---|---|
|Обязательная|`Database $db`|Без неё объект не работает|
|Опциональная|`Logger $logger = null`|Объект работает и без неё|

---

### 🧪 Живой пример:

```php
class Order {
    public function __construct(
        public int $id,
        public float $amount
    ) {}

    public function printSummary() {
        echo "Заказ №$this->id на сумму $this->amount ₽";
    }
}

$order = new Order(101, 5500.0);
$order->printSummary(); // Заказ №101 на сумму 5500 ₽
```

---

### ⚠️ Ошибки, которых стоит избегать:

- Не вызывать `__construct()` вручную — это делает `new`. 
- Не переусложнять конструктор множеством параметров — выносите зависимости в отдельные классы. 
- Если используете `nullable`, проверяйте наличие значения перед использованием.

### 🧠 Упражнение:

Пусть студенты напишут класс `Book`, который имеет:

- Название (`title`)
- Автора (`author`)
- Год выпуска (`year`, по умолчанию текущий)

И метод `describe()`, который выводит описание книги.

```php
$book = new Book("Мастер и Маргарита", "Булгаков");
$book->describe(); // "Мастер и Маргарита" — Булгаков (2025)
```
