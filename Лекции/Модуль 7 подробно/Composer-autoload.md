### **Composer-autoload: `composer init`, `composer dump-autoload`, PSR-4, загрузка классов «по папкам»**

---

### 📌 Цель блока:

Объяснить, как Composer помогает автоматически подключать классы (автозагрузка) с помощью стандарта PSR-4. Научить студентов инициализировать проект, прописывать автозагрузку и подключать классы через пространства имён.

---

### 📖 Теория

#### 🧰 Что такое автозагрузка?

Автозагрузка (autoloading) — это механизм, при котором PHP **сам подключает нужные файлы с классами** при их первом использовании.

До этого:

```php
require 'src/Models/User.php';
```

С Composer-автозагрузкой:

```php
use App\Models\User;
// Composer сам подключит src/Models/User.php
```

---

### ⚙️ Шаги настройки автозагрузки через Composer

---

### 🟦 Шаг 1 — `composer init`

Выполните в корне проекта:

```bash
composer init
```

Composer задаст несколько вопросов:

- имя пакета (можно просто `my/app`)
- описание, автор и т.п.
- оставить `src` как директорию по умолчанию

В итоге создаётся файл `composer.json`.

---

### 🟦 Шаг 2 — структура проекта

Создайте папку с исходниками:

```
project/
├── composer.json
├── src/
│   └── Models/
│       └── Product.php
├── vendor/
└── index.php
```

Пример класса:

```php
// src/Models/Product.php
namespace App\Models;

class Product {
    public function getName() {
        return "Товар";
    }
}
```

---

### 🟦 Шаг 3 — настроить PSR-4 автозагрузку

В `composer.json` добавьте:

```json
"autoload": {
    "psr-4": {
        "App\\": "src/"
    }
}
```

Полный пример `composer.json`:

```json
{
    "name": "my/app",
    "autoload": {
        "psr-4": {
            "App\\": "src/"
        }
    },
    "require": {}
}
```

---

### 🟦 Шаг 4 — `composer dump-autoload`

Обновляем список автозагружаемых классов:

```bash
composer dump-autoload
```

Появляется папка `vendor/` и файл `vendor/autoload.php`.

---

### 🟦 Шаг 5 — Использование в `index.php`

```php
require __DIR__ . '/vendor/autoload.php';

use App\Models\Product;

$product = new Product();
echo $product->getName(); // Товар
```

Composer сам найдёт класс `App\Models\Product` в `src/Models/Product.php`.

---

### 🧪 Что делает PSR-4?

PSR-4 определяет соответствие:

- Пространства имён → папки 
- Названия классов → имена файлов 

Пример:

- Класс: `App\Services\Mailer` 
- Файл: `src/Services/Mailer.php` 

Composer ищет по правилу:

```
App\ → src/
```

```bash
php index.php
```

✅ Если всё сделано верно, вы увидите:

```
Товар
```

### ⚠️ Частые ошибки:

|Ошибка|Причина|
|---|---|
|Класс не найден|забыли `composer dump-autoload`|
|Пространство имён не совпадает с папкой|ошибка в `psr-4`|
|Неверный регистр букв|Windows может простить, Linux — нет|

Вот развёрнутые **ответы на вопросы** из блока о Composer-autoload и PSR-4:

---

### ❓ Зачем нужен `composer dump-autoload`?

**Ответ:**  
Команда `composer dump-autoload` генерирует (или обновляет) файл автозагрузки `vendor/autoload.php`, на основе настроек из `composer.json`.

Когда её нужно вызывать:

- после добавления новых классов; 
- после изменения пространства имён или структуры каталогов; 
- после изменения раздела `autoload` в `composer.json`. 

Если забыть вызвать `dump-autoload`, новые классы не будут найдены, и появится ошибка `Class not found`.

---

### ❓ Что означает `"App\\": "src/"` в `psr-4`?

**Ответ:**  
Это правило автозагрузки, которое говорит:

> «Если используется пространство имён, начинающееся с `App\`, искать соответствующие классы в папке `src/`»

Примеры:

|Класс|Файл|
|---|---|
|`App\Models\Product`|`src/Models/Product.php`|
|`App\Services\Mailer`|`src/Services/Mailer.php`|

Это реализация стандарта **PSR-4**, где:

- часть до `\\` — корень пространства имён; 
- значение — путь к папке, где искать классы. 

---

### ❓ Где хранится логика автозагрузки?

**Ответ:**  
В файле:

```php
vendor/autoload.php
```

Этот файл подключает все зависимости и классы, указанные в `composer.json`, а также все классы, попадающие под автозагрузку PSR-4.

Вы подключаете его в `index.php`:

```php
require __DIR__ . '/vendor/autoload.php';
```

Дальше всё работает автоматически: PHP вызывает автозагрузчик, который по имени класса определяет путь к нужному `.php` файлу.
