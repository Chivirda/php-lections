
## 🔹 2-й академический час — 0:00–0:15

### **Пространства имён: `namespace App\Models;`, `use`, коллизии имён**

---

### 📌 Цель блока:

Познакомить студентов с механизмом пространств имён (namespaces) в PHP, объяснить, как они помогают организовать код и решать конфликты имён между классами. Также показать ключевые конструкции: `namespace`, `use`, `as`.

---

### 📖 Теория

#### 🔧 Что такое пространство имён?

Пространство имён (namespace) — способ **логически группировать классы**, чтобы избежать конфликтов имён и улучшить структуру проекта.

**Аналогия:**  
В одной школе может быть два человека по имени «Аня», но в разных классах:

- `1А\Аня`
- `3Б\Аня`

Так же и в коде: могут быть `App\Models\User` и `App\Controllers\User`.

---

### 📦 Объявление пространства имён

```php
// Файл: src/Models/User.php
namespace App\Models;

class User {
    public function hello() {
        echo "Я — модель User";
    }
}
```

Теперь полное имя класса: `App\Models\User`

---

### 📥 Использование класса с `use`

```php
// Файл: index.php
require 'src/Models/User.php';

use App\Models\User;

$user = new User();
$user->hello();
```

---

### ❗ Без `use` — длинное имя

```php
$user = new \App\Models\User();
```

Писать полностью можно, но это неудобно. Лучше использовать `use`.

---

### 🧨 Коллизии имён

Если в проекте есть два класса с одинаковым именем, например:

```php
namespace App\Models;
class User {}

namespace App\Controllers;
class User {}
```

Чтобы использовать оба:

```php
use App\Models\User as ModelUser;
use App\Controllers\User as ControllerUser;

$model = new ModelUser();
$controller = new ControllerUser();
```

---

### 🧱 Структура проекта и автозагрузка

С помощью пространств имён можно логически организовать проект:

```
src/
  Models/
    User.php      → namespace App\Models;
  Controllers/
    User.php      → namespace App\Controllers;
```

---

### 🚫 Ошибки, которых нужно избегать:

|Ошибка|Почему плохо|
|---|---|
|Отсутствие `namespace` в классе|Нарушение автозагрузки, конфликт имён|
|Использование нескольких `namespace` в одном файле|Нарушает читаемость и предсказуемость|
|Неправильный `use` (опечатка)|Класс не будет найден|

### 🧪 Упражнение:

Создать два класса `User`:

- `App\Models\User` с методом `describe()` → «Я модель User»
- `App\Controllers\User` с методом `describe()` → «Я контроллер User»

В `index.php`:

```php
use App\Models\User as ModelUser;
use App\Controllers\User as ControllerUser;

$model = new ModelUser();
$controller = new ControllerUser();

$model->describe();      // Я модель User
$controller->describe(); // Я контроллер User
```
