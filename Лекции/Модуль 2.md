## **Модуль 2 — Основы среды разработки и синтаксиса PHP**

---

### **1-й академический час (45 минут)**

#### **0:00–0:10 — [Установка окружения](./Модуль%202%20подробно/Установка%20окружения.md)**

**Цель:** Ознакомить студентов с возможностями запуска PHP-кода на локальной машине.

**Варианты установки:**

1. **XAMPP/MAMP** — готовый пакет, включает Apache + PHP + MySQL.
    - Удобен для начинающих.
    - Достаточно установить и запустить Apache.
    - Корневая папка: `htdocs`.
2. **Docker**
    - Пример команды:
  ```bash
docker run -d -p 8080:80 -v ${PWD}:/var/www/html php:8.3-apache
```
    - Позволяет изолировать окружение, использовать нужные версии PHP.

3. **Встроенный сервер PHP**
    - Минимальный способ быстро запустить проект:
```bash
php -S localhost:8000
```

    - Работает из любой папки, идеально для простых тестов.


📌 _Совет: пусть студенты выберут удобный для них способ и протестируют работу в браузере._

---

#### **0:10–0:20 — [Composer](./Модуль%202%20подробно/Composer.md)**

**Цель:** Показать, как управлять зависимостями и автозагрузкой в PHP-проектах.

1. **Инициализация проекта**
```bash
composer init
```
    
    - Добавление секции `autoload`.
    
2. **Автозагрузка по стандарту PSR-4**  
    В `composer.json`:
    
```json
"autoload": {
    "psr-4": {
        "App\\": "src/"
    }
}
```

3. **Установка пакета Monolog**

```bash
composer require monolog/monolog
```

4. **Пример подключения**

```php
require 'vendor/autoload.php';
use Monolog\Logger;
use Monolog\Handler\StreamHandler;

$log = new Logger('name');
$log->pushHandler(new StreamHandler('app.log', Logger::WARNING));
$log->warning('Предупреждение!');
```


---

#### **0:20–0:35 — [PHP-теги](./Модуль%202%20подробно/PHP-теги.md)**

**Варианты PHP-тегов:**

- `<?php … ?>` — основной и обязательный.
- `<?= … ?>` — сокращение для `echo`.
- `<? … ?>` — _не использовать!_ Устаревшая форма, отключается через `short_open_tag`.

**Настройка в `php.ini`:**

```ini
short_open_tag = Off
```

**Совет:** Всегда используйте `<?php` и `<?=` для совместимости.

---

#### **0:35–0:45 — [Первая программа](./Модуль%202%20подробно/Первая%20программа.md)**

Создаём файл `hello.php`:

```php
<?php
echo "Привет, мир!";
```

**Запуск:**

- В браузере: `http://localhost/hello.php`
- В CLI:
```bash
php hello.php
```


📌 _Поясните различия между запуском через браузер и CLI: доступность суперглобалов, поведение `$_GET`, отсутствие HTML-обёртки._

### **2-й академический час (45 минут)**

#### **0:00–0:20 — [Синтаксис и переменные](./Модуль%202%20подробно/Синтаксис%20и%20переменные.md)**

1. **Именование переменных**
    - `$camelCase` — принятое соглашение.
    - Нельзя начинать имя с цифры.
    - Примеры:
```php
$name = "Иван";
$userAge = 30;
```

2. **Область видимости**

- `global`, `local`, `static`.
   
- Пример:

```php
function test() {
	$x = 5;
	echo $x;
}
```

3. **Динамические переменные**
```php
$name = "hello";
$$name = "Привет!";
echo $hello; // Привет!
```

4. **Суперглобальные переменные**
   
- `$_GET`, `$_POST`, `$_SESSION`, `$_COOKIE`, `$_SERVER`, `$_FILES`.
   
- Пример использования `$_GET`:

```php
echo $_GET['name'];
```

#### **0:20–0:35 — [Типы данных](./Модуль%202%20подробно/Типы%20данных.md)**

**Скалярные:**

- `int`, `float`, `bool`, `string`

**Составные:**

- `array`, `object`

**Специальные:**

- `callable`, `iterable`, `null`

**Смешанные:**

- `mixed`, `int|float` (union types, с PHP 8.0)

Примеры:

```php
$number = 42; // int
$price = 99.99; // float
$isReady = true; // bool
$name = "Sergey"; // string

$list = [1, 2, 3]; // array
$obj = (object) ['a' => 1]; // object
```

#### **0:35–0:40 — Лайв-код: [Type Juggling](./Модуль%202%20подробно/Type%20Juggling.md)**

Пример “магии типов” в PHP:

```php
var_dump("5" == 5);  // true
var_dump("5" === 5); // false
```

**Объяснение:**

- `==` приводит типы автоматически (строка и число → оба становятся числом).
- `===` строгое сравнение без преобразования типов.
