
### ⏰ **0:00–0:12** — **Иерархия Throwable в PHP**

#### 🎯 Цель блока:

Познакомить студентов с базовыми понятиями обработки исключений в PHP, объяснить, чем отличаются `Exception`, `Error`, и `\Throwable`, и как создавать собственные исключения.

---

### 📚 Теория:

#### 🔹 Что такое исключения:

Исключения — это способ обработки **ошибок, которые могут произойти во время выполнения программы**, но не связаны с синтаксическими ошибками. В PHP они реализованы как объекты.

#### 🔹 Базовая иерархия:

С PHP 7 введён единый интерфейс `\Throwable`, от которого наследуются два типа:

- `Exception` — классическая бизнес-логика (например, "не найден пользователь", "ошибка валидации").  
- `Error` — критические ошибки на уровне интерпретатора (например, "неправильный тип данных", "не найден класс").  

```plaintext
          \Throwable
          /        \
  \Exception     \Error
```

#### 🔹 Зачем это нужно:

- Можно обрабатывать как "мягкие", так и "жёсткие" ошибки с помощью `catch`.
- Позволяет централизованно логировать и контролировать поведение при ошибках.

---

### 🧱 Создание кастомного исключения:

Можно создавать собственные типы исключений, чтобы точнее описывать проблему:

```php
class ValidationException extends \Exception {}
```

Ты наследуешь от `\Exception` и можешь добавить специфичную логику (например, коды ошибок, шаблоны сообщений).

---

### 🧪 Пример использования:

```php
class ValidationException extends \Exception {}

function registerUser($email) {
    if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
        throw new ValidationException("Некорректный email: $email");
    }
    echo "Пользователь с email $email успешно зарегистрирован.";
}

try {
    registerUser("invalid_email");
} catch (ValidationException $e) {
    echo "Ошибка валидации: " . $e->getMessage();
}
```

---

### ❗ Важные моменты для обсуждения:

- Все исключения можно поймать через `catch (\Throwable $e)`.
- Лучше использовать собственные типы исключений вместо `\Exception`, чтобы не использовать магические строки.
- Кастомные исключения особенно полезны в сервисах, которые предоставляют API, — можно возвращать точные коды ошибок.
