## 🔗 Основная структура реляционной базы данных

### Иерархия:

1. **Database (База данных)** — логическая единица, объединяющая таблицы и другие объекты.
2. **Table (Таблица)** — упорядоченное хранение однотипных данных в виде строк и столбцов.
3. **Row (Строка)** — конкретная запись в таблице (объект, сущность).
4. **Column (Столбец)** — характеристика (свойство) записи.

📊 **Пример**:

|id|name|email|
|--:|---|---|
|1|Иван|[ivan@example.com](mailto:ivan@example.com)|
|2|Ольга|[olga@example.com](mailto:olga@example.com)|

## 🗄️ Основные типы данных в MySQL

### Числовые типы:

- `INT`, `BIGINT` — целые числа.
- `DECIMAL(10,2)` — точные числа (например, деньги).

### Строковые типы:

- `VARCHAR(n)` — строки переменной длины (до n символов).
- `TEXT` — длинные текстовые данные (до 64 КБ).

### Даты и время:

- `DATE` — только дата (ГГГГ-ММ-ДД).
- `DATETIME` — дата и время (ГГГГ-ММ-ДД ЧЧ:ММ:СС).
- `TIMESTAMP` — аналог DATETIME, привязан к временной зоне.

### Структурированные данные:

- `JSON` — для хранения полуструктурированных данных.

🔹 **Пример**:

```sql
CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(255) UNIQUE,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    settings JSON
);
```

---

## 🔑 Ключи

### Первичный ключ (PRIMARY KEY):

- Гарантирует **уникальность** каждой строки.
- Обычно это колонка `id` с автоинкрементом.

🔹 **Пример**:

```sql
id INT PRIMARY KEY AUTO_INCREMENT
```

### Внешний ключ (FOREIGN KEY):

- Обеспечивает **связь между таблицами**.
- Поддерживает ссылочную целостность.

🔹 **Пример**:

```sql
FOREIGN KEY (user_id) REFERENCES users(id)
```

---

## 🚀 Индексы

- **Индекс (INDEX)** — структура, ускоряющая поиск и сортировку данных.
- Автоматически создаётся для PRIMARY KEY и UNIQUE.
- Для часто используемых в WHERE, JOIN, ORDER BY — индекс обязателен.

🔹 **Пример**:

```sql
CREATE INDEX idx_email ON users(email);
```

---

## 📝 Практический пример:

### Таблица заказов:

```sql
CREATE TABLE orders (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT,
    product_name VARCHAR(255),
    amount DECIMAL(10, 2),
    order_date DATE,
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

- `id` — первичный ключ.
- `user_id` — внешний ключ, связывает заказ с пользователем.
- Индекс по умолчанию создаётся на PRIMARY KEY.
