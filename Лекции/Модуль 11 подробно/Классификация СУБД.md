### 🗂 Основные типы СУБД:

---

### 1. **Реляционные СУБД (RDBMS)**

- **Основа** — таблицы со строками и колонками.
- Данные связаны между собой через **ключи** (primary, foreign).
- Используют **SQL** для запросов.
- Поддерживают **ACID-транзакции**.
- Примеры: **MySQL, MariaDB, PostgreSQL, Oracle, MS SQL Server**.

🔹 Применение:

- Корпоративные системы.
- Сайты, CRM, ERP.
- Финансовые приложения.

---

### 2. **Документо-ориентированные СУБД**

- Хранят данные в виде **документов** (обычно JSON или BSON).
- Нет строгой схемы, каждый документ может быть разным.
- Гибкость для динамически меняющихся данных.
- Примеры: **MongoDB, CouchDB, RavenDB**.

🔹 Применение:

- Прототипирование.
- Хранение профилей пользователей.
- Системы с гибкими данными (каталоги товаров).

---

### 3. **Колоночные СУБД**

- Данные хранятся и обрабатываются **по колонкам**, а не по строкам.
- Очень эффективны для аналитики и агрегаций по большим объёмам данных.
- Примеры: **ClickHouse, Apache Cassandra, HBase**.

🔹 Применение:

- BI-системы (бизнес-аналитика).
- Веб-статистика.
- Хранилища больших данных (Data Warehouse).

---

### 4. **Графовые СУБД**

- Основные сущности: **вершины (nodes)** и **рёбра (edges)**.
- Удобны для представления связей между объектами.
- Запросы работают через обход графов.
- Примеры: **Neo4j, ArangoDB, OrientDB**.

🔹 Применение:

- Социальные сети.
- Поисковые системы.
- Рекомендательные сервисы.

---

### 5. **Time-Series СУБД**

- Оптимизированы для хранения и обработки **временных рядов**.
- Основное: timestamp + значение.
- Быстрые вставки, агрегаты по времени.
- Примеры: **InfluxDB, TimescaleDB, Prometheus**.

🔹 Применение:

- Мониторинг серверов и приложений.
- IoT-устройства (температура, давление, скорость).
- Финансовые временные ряды.

---

### 🧠 Визуальное сравнение:

|Тип СУБД|Особенности|Примеры|Где применяют|
|---|---|---|---|
|Реляционные|SQL, связи между таблицами|MySQL, PostgreSQL|Веб-приложения, финансы|
|Документные|JSON-документы, динамическая схема|MongoDB|Каталоги, профили|
|Колонко-ориентированные|Хранение по колонкам|ClickHouse|Аналитика, отчеты|
|Графовые|Связи между сущностями|Neo4j|Соцсети, рекомендации|
|Time-Series|Временные ряды|InfluxDB|Мониторинг, IoT|
