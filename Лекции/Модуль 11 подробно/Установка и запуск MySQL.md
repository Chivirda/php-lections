## 🔧 Установка MySQL через Docker Compose

### Почему Docker?

- **Быстро**: не надо настраивать вручную зависимости.
- **Изолированно**: не ломает вашу систему.
- **Кроссплатформенно**: одинаково работает на Windows, Linux, MacOS.

---

### Минимальный docker-compose.yml

```yaml
version: '3.8'

services:
  mysql:
    image: mysql:8.2
    restart: always
    environment:
      MYSQL_ROOT_PASSWORD: secret
    ports:
      - "3306:3306"
```

🔹 **Объяснение параметров**:

- `image: mysql:8.2` — версия образа MySQL.
- `MYSQL_ROOT_PASSWORD` — задаём пароль для пользователя root.
- `ports` — проброс порта 3306 на локальную машину.
- `restart: always` — автоматический рестарт при сбое.

---

### Команды запуска:

```bash
docker-compose up -d
```

- `-d` — запускаем в фоне.

Проверка статуса:

```bash
docker ps
```

## 🖥️ Подключение к MySQL

### 1. **Вход внутрь контейнера**:

```bash
docker exec -it <container_id> bash
```

### 2. **Запуск MySQL CLI**:

```bash
mysql -u root -p
```

- Вводим пароль (`secret`).

---

### 3. **Проверка версии MySQL**:

```sql
SELECT VERSION();
```

- Убедимся, что поднялась именно нужная версия (8.2).

---

## 🛠️ Клиенты для работы с MySQL

### 1. **CLI (командная строка)**

- Лёгкий и быстрый способ.
- Хорош для админов, автоматизации, скриптов.

### 2. **MySQL Workbench**

- Официальный GUI от Oracle.
- Визуальное проектирование БД, удобный редактор запросов.

### 3. **DBeaver**

- Мультиформатный клиент (MySQL, PostgreSQL, SQLite и др.).
- Open Source, более удобен для повседневной работы.

---

## 🔥 Мини-дема:

1. Запускаем контейнер.
2. Заходим в него через `docker exec`.
3. Логинимся через `mysql -u root -p`.
4. Выполняем `SELECT VERSION();` для проверки.
5. Альтернативно — подключаемся через DBeaver или Workbench.
