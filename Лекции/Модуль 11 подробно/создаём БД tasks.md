## 📝 Условие мини-демо:

- Создаём базу данных **tasks**.
- В ней создаём таблицу **users** со следующими полями:
    - `id` — автоинкремент, первичный ключ.
    - `name` — строка, обязательное поле.
    - `email` — уникальный адрес электронной почты.

---

## 🚀 Шаг 1. Создание базы данных

```sql
CREATE DATABASE tasks;
```

- Создаётся новая БД с именем `tasks`.

### Переход в базу:

```sql
USE tasks;
```

- Теперь все операции будут выполняться в этой базе.

---

## 🚀 Шаг 2. Создание таблицы users

```sql
CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(255) UNIQUE
);
```

🔍 **Что здесь происходит**:

- `id INT PRIMARY KEY AUTO_INCREMENT`: уникальный идентификатор для каждой записи, автоматически увеличивается.
- `name VARCHAR(100) NOT NULL`: обязательное поле для имени пользователя.
- `email VARCHAR(255) UNIQUE`: адрес электронной почты, который должен быть уникальным.

---

## 🚀 Шаг 3. Проверка таблицы

Выводим список таблиц:

```sql
SHOW TABLES;
```

- Должен появиться список, где есть таблица `users`.

Смотрим структуру таблицы:

```sql
DESCRIBE users;
```

- Отобразятся все столбцы, их типы и ограничения:
    - Field | Type | Null | Key | Default | Extra


---

## 🧪 Шаг 4. Тестовая вставка данных

```sql
INSERT INTO users (name, email) VALUES ('Иван Иванов', 'ivan@example.com');
```

- Проверяем работу ограничений:
    - Если попробуем вставить второго пользователя с тем же email — будет ошибка из-за UNIQUE.
