## 🟢 Основные особенности MySQL:

### 1. **Editions — Community vs Enterprise**

- **MySQL Community Edition**:
    - Бесплатная и с открытым исходным кодом.
    - 99% функционала достаточно для большинства проектов.
    - Входит в стандартные репозитории Linux.
- **MySQL Enterprise Edition**:
    - Платная, поддержка от Oracle.
    - Дополнительные инструменты (backup, firewall, мониторинг).
    - Используется в крупных корпоративных проектах.

🔹 **Для разработчиков** — Community более чем достаточно.

---

### 2. **Storage Engines — движки хранения**

- **InnoDB** (по умолчанию):
    - Поддержка **транзакций** (ACID).
    - Внешние ключи (FOREIGN KEY).
    - Блокировки на уровне строки.
    - Журналирование изменений.
    - Надёжность, целостность данных.
- **MyISAM** (устаревший, но иногда встречается):
    - Нет транзакций.
    - Блокировки на уровне таблицы.
    - Быстрее на чтение, но небезопасен при сбоях.
- Другие движки: MEMORY, CSV, ARCHIVE — узкоспециализированные.

🔹 **В реальной жизни** — всегда выбирайте InnoDB.

---

### 3. **JSON-тип данных**

- Начиная с MySQL 5.7 поддерживается полноценный тип JSON
- Позволяет хранить полуструктурированные данные.
- Есть функции для поиска и модификации JSON (JSON_EXTRACT, JSON_SET).
- Удобно для хранения динамических настроек, метаданных.

🔹 **Важно**: это не замена MongoDB, но хорошее подспорье для гибкости.

---

### 4. **CTE — Common Table Expressions**

- Начиная с MySQL 8.0.
- Запросы вида:

```sql
WITH recent_orders AS (
  SELECT * FROM orders WHERE order_date > '2024-01-01'
)
SELECT * FROM recent_orders WHERE total > 1000;
    ```

- Упрощают чтение сложных запросов.
- Позволяют строить **рекурсивные выборки**.

---

### 5. **Window Functions (Оконные функции)**

- Тоже с версии 8.0.
- Позволяют делать агрегаты по "окнам" строк без группировки.
- Примеры:
    - Нумерация строк (`ROW_NUMBER()`),
    - Скользящее среднее (`AVG() OVER()`),
    - Расчёт разницы между строками (`LAG()`, `LEAD()`).

🔹 **Реальный кейс**: строим рейтинг пользователей по баллам.

---

### 📝 Сравнение InnoDB vs MyISAM:

|Параметр|InnoDB|MyISAM|
|---|---|---|
|Транзакции|✅ Да|❌ Нет|
|Внешние ключи|✅ Да|❌ Нет|
|Блокировки|Строки|Таблицы|
|Надёжность при сбоях|Высокая|Низкая|
|Производительность на чтение|Средняя|Высокая|
|Поддержка полнотекстового поиска|✅ Да (с 5.6)|✅ Да|

### 📝 Итог блока:

- MySQL — надёжная, быстрая и бесплатная СУБД для веба.
- InnoDB — основной движок хранения.
- Современные возможности (JSON, CTE, оконные функции) приближают MySQL к возможностям PostgreSQL.
- Для продакшна — всегда InnoDB, MyISAM — только для специфичных задач.
