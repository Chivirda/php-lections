## 🔹 1-й академический час

### ⏱ 0:00–0:15 — **[Класс & объект](./Модуль%207%20подробно/Класс%20&%20объект.md)**

**Ключевые понятия:**

- Класс — шаблон для объектов.
- Объект — экземпляр класса.
- Объявление класса: `class User { }` 
- Свойства (переменные): `public $name;` 
- Методы (функции): `public function sayHello() { }` 
- `$this` — текущий объект внутри метода. 
- Вызов:

```php
$user = new User();  
$user->name = "Tim";  
$user->sayHello();
```


**Интерактив:**  
Создаём класс `User` с методом `sayHello()` и выводим приветствие.

---

### ⏱ 0:15–0:25 — **[Конструктор](./Модуль%207%20подробно/Конструктор.md)**

**Ключевые понятия:**

- Метод `__construct()` вызывается при создании объекта.
- Передача обязательных и необязательных аргументов:
```php
class Product {
	public function __construct(public string $name, public float $price = 100) {}
}
```

- Разбор зависимости:
    - Обязательная: `User($authService)` 
    - Опциональная: `LoggerInterface $logger = null` 

**Интерактив:**  
Пример класса `Book` с названием и ценой, обсуждение значения по умолчанию.

---

### ⏱ 0:25–0:35 — **[Модификаторы доступа](./Модуль%207%20подробно/Модификаторы%20доступа.md)**

**Ключевые понятия:*  
- `public`: доступ отовсюду.
- `protected`: доступ из класса и наследников.
- `private`: доступ только внутри класса.

```php
class Secret {
    private string $code = "1234";
    public function getCode() {
        return $this->code;
    }
}
```

- Инкапсуляция = скрытие деталей реализации.  
    Пример: скрываем поля, оставляем только методы `get()` и `set()`.

**Интерактив:**  
Пишем класс `BankAccount` с `private $balance` и методами `deposit()`, `getBalance()`.

---

### ⏱ 0:35–0:45 — **[Static](./Модуль%207%20подробно/Static.md)**

**Ключевые понятия:**

- `static` — принадлежит классу, а не объекту.
- Счётчик экземпляров через статическое поле:

```php
class Counter {
	public static int $count = 0;
	public function __construct() {
		self::$count++;
	}
}
```

- Вызов: `Counter::$count`
- Синглтон (антипаттерн):
    - Пример `Singleton::getInstance()`
    - Почему плохо: сложность тестирования, глобальное состояние.

**Интерактив:**  
Создаём класс `Logger` с `static function log($msg)` и записываем в `log.txt`.

## 🔹 2-й академический час

### ⏱ 0:00–0:15 — **[Пространства имён](./Модуль%207%20подробно/Пространства%20имён.md)**

**Ключевые понятия:**

- Пространство имён позволяет группировать классы.

```php
namespace App\Models;

class User { }
```

- Подключение:

```php
use App\Models\User;
```

- Коллизии имён:

```php
use App\Controllers\User as ControllerUser;
```


**Интерактив:**  
Создаём два класса `User` в разных пространствах (`Models`, `Services`), решаем конфликт через alias.

---

### ⏱ 0:15–0:30 — **[Composer-autoload](./Модуль%207%20подробно/Composer-autoload.md)**

**Ключевые понятия:**

- Инициализация:

```bash
composer init
```

- PSR-4 автозагрузка:

```json
"autoload": {
  "psr-4": {
	"App\\": "src/"
  }
}
```

- Обновление:

```bash
composer dump-autoload
```

- Классы автоматически загружаются из нужных файлов по имени.

**Интерактив:**  
Строим структуру `/src/Models/Product.php`, добавляем класс и проверяем автозагрузку.

### ⏱ 0:30–0:40 — **Живой пример: [Product](./Модуль%207%20подробно/Product.md)**

**Задача:**

- Класс `Product` с `name`, `price`.
- Статическое поле `VAT = 0.2` (20%).
- Метод `getPriceWithVat()`

```php
class Product {
    public static float $vat = 0.2;
    public function __construct(public string $name, public float $price) {}

    public function getPriceWithVat(): float {
        return $this->price * (1 + self::$vat);
    }
}
```

- Тестируем: создаём `Product`, вызываем метод, подключаем через autoload.
