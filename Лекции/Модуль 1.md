## **0:00–0:15 — [Эволюция бэкенда](./Модуль%201%20подробно/Эволюция%20бэкенда.md)**

**Ключевые пункты:**

- CGI (Common Gateway Interface) — запуск каждого запроса как отдельного процесса. Медленно, но просто.
- FastCGI — решение проблемы производительности за счёт постоянного процесса.
- WSGI/PSGI — унифицированные интерфейсы для Python и Perl.
- Концепция `request → обработка → response`.

**Интерактив:**

- Вопрос в начале: **«Какие языки вы уже использовали на сервере?»**
    - Можно собрать ответы на доске или в чате (если онлайн).
    - Быстрое обсуждение: как реализовывался «ответ» пользователю в этих языках.

## **0:15–0:30 — [Обзор популярных языков](./Модуль%201%20подробно/Обзор%20популярных%20языков.md)**

**Ключевые пункты:**

- Кратко по каждому языку:
    - **PHP** — низкий порог входа, огромная база CMS.
    - **Node.js** — JavaScript на сервере, отлично для real-time.
    - **Python** — читаемость, научные библиотеки.
    - **Ruby** — разработка через удовольствие (Rails).
    - **Java/Kotlin** — крупные системы, безопасность, Android.
    - **C#/.NET** — интеграция с Windows, корпоративные решения.
    - **Go, Rust** — высокопроизводительные системы, микросервисы.
- **Критерии выбора языка** 
    1. Порог входа
    2. Производительность
    3. Экосистема
    4. Найм (доступность специалистов)

**Интерактив:**

- Создаём таблицу на доске «Язык vs Use-cases» вместе:
    
    ```
    Язык     | Подходит для
    ---------|---------------
    PHP      | CMS, ecommerce, API
    Node.js  | Real-time, SPA
    Python   | ML, Django-приложения
    ...
    ```
