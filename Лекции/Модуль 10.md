## 📘 **Модуль 10 — Laravel за 90 минут: компоненты и первый CRUD**

### 🔹 1-й академический час (45 мин)

#### ⏱ 0:00–0:10 — [Установка](./Модуль%2010%20подробно/Установка.md)  

**Цель:** создать Laravel-проект и познакомиться с его структурой.

**Ключевые шаги:**

```bash
composer create-project laravel/laravel demo
# Или с помощью Laravel Installer:
laravel new demo
```

**Структура проекта:**

- `app/` — бизнес-логика (Models, Providers, Services).
- `routes/` — маршруты (`web.php`, `api.php`).
- `resources/views/` — шаблоны Blade.
- `database/` — миграции, сидеры, factories.
- `public/` — точка входа `index.php`.
- `.env` — переменные окружения.

---

#### ⏱ 0:10–0:20 — [Маршрутизация](./Модуль%2010%20подробно/Маршрутизация.md)  

**Файл:** `routes/web.php`

**Примеры:**

```php
use Illuminate\Support\Facades\Route;

Route::get('/', function () {
    return view('welcome');
});

Route::get('/hello/{name}', function ($name) {
    return "Hello, $name!";
});

Route::post('/form', [FormController::class, 'submit']);
```

- Поддержка `get`, `post`, `put`, `delete`, `patch`.
- Роут-параметры: обязательные и опциональные (`/user/{id?}`).

---

#### ⏱ 0:20–0:35 — [Контроллеры](./Модуль%2010%20подробно/Контроллеры.md) 

**Создание:**

```bash
php artisan make:controller PostController
php artisan make:controller PostController --resource
```

**Методы REST-контроллера:**

```php
public function index() { ... }    // GET /posts
public function store(Request $r) { ... }  // POST /posts
public function show($id) { ... } // GET /posts/{id}
public function update(Request $r, $id) { ... } // PUT
public function destroy($id) { ... } // DELETE
```

**Single Action Controller:**

```bash
php artisan make:controller HelloController --invokable
```

---

#### ⏱ 0:35–0:45 — [Blade-шаблоны](./Модуль%2010%20подробно/Blade-шаблоны.md) 

**Простой шаблон `resources/views/hi.blade.php`:**

```blade
@extends('layouts.app')

@section('content')
    <h1>Hello, {{ $name }}</h1>
    <form method="POST" action="/submit">
        @csrf
        <input name="email">
        <button type="submit">Send</button>
    </form>
@endsection
```

- `@extends`, `@section`, `@yield`
- `{{ }}` — авто-escape
- `@csrf` — защита от CSRF-атак

### 🔹 2-й академический час (45 мин)

#### ⏱ 0:00–0:12 — [Eloquent ORM](./Модуль%2010%20подробно/Eloquent%20ORM.md)

**Создание модели и миграции:**

```bash
php artisan make:model Post -m
```

**Миграция:**

```php
Schema::create('posts', function (Blueprint $table) {
    $table->id();
    $table->string('title');
    $table->text('body');
    $table->timestamps();
});
```

```bash
php artisan migrate
```

**Модель:**

```php
class Post extends Model {
    protected $fillable = ['title', 'body'];
}
```

**Работа с моделью:**

```php
Post::all();
Post::create(['title' => 'Hello', 'body' => 'World']);
```

---

#### ⏱ 0:12–0:22 — [Миграции и сидеры](./Модуль%2010%20подробно/Миграции%20и%20сидеры.md)  

```bash
php artisan make:migration add_votes_to_posts_table
php artisan migrate:rollback
php artisan make:seeder PostSeeder
```

**Seeder:**

```php
Post::factory()->count(10)->create();
```

Запуск:

```bash
php artisan db:seed
```

---

#### ⏱ 0:22–0:30 — [Валидатор & Form Request](./Модуль%2010%20подробно/Валидатор%20&%20Form%20Request.md)  

```bash
php artisan make:request StorePostRequest
```

**StorePostRequest:**

```php
public function rules() {
    return [
        'title' => 'required|string|max:255',
        'body' => 'required',
    ];
}
```

**В контроллере:**

```php
public function store(StorePostRequest $request) {
    Post::create($request->validated());
}
```

#### ⏱ 0:30–0:38 — [Middleware, Facades, Service Container](./Модуль%2010%20подробно/Middleware,%20Facades,%20Service%20Container.md)  

**Middleware:**

- Проверка авторизации, CSRF, логирование и др.
- Пример кастомного:


**Facades:**

```php
Cache::remember('key', 600, fn() => Post::all());
```

**Dependency Injection:**

```php
public function __construct(LoggerInterface $logger) {
    $this->logger = $logger;
}
```
